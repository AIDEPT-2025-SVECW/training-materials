📌 Request Parameters vs Path Variables

Designing RESTful Endpoints with @PathVariable and @RequestParam

🎓 Real-World Analogy: College Student Portal

Imagine your college's online portal. How does the backend retrieve a specific student's profile vs filtering batch records?

🆔 Path Variable = Student Reg No

URL: GET /students/21B91A0501

When you open the profile of one specific student, the Registration Number (21B91A0501) is embedded in the URL path. It uniquely identifies which specific student to fetch.

🔍 Request Param = Filter Options

URL: GET /students?branch=CSE&sem=5&minGpa=8.5

When HOD views the student directory and filters by Branch, Semester, or Min GPA, these appear after ?. They don't change the resource (still /students), but filter the results!

1. Core Concepts

📍 Path Variables (URI Path)

Used to identify a specific resource directly within the URL path hierarchy.

Example URL: /students/21B91A0501 or /departments/cse/students/501

  • Required part of the endpoint path
  • Identifies a single resource instance (e.g. Student Reg No)
  • Spring Boot: @PathVariable
  • Express.js: req.params

🔍 Request Parameters (Query String)

Used to filter, sort, search, or paginate data collections.

Example URL: /students?branch=CSE&status=active&page=1

  • Appears after ? as key-value pairs
  • Usually optional with default values
  • Spring Boot: @RequestParam
  • Express.js: req.query

📋 Side-by-Side Comparison

Feature Path Variable (e.g. Student Reg No) Request / Query Parameter (e.g. Branch/GPA)
Primary Purpose Identifies specific student record Filters/sorts list of students
URL Structure /students/{regNo} /students?branch=CSE&minGpa=8.0
Optionality Mandatory (URL broken without it) Optional (can fallback to defaults)
Spring Boot Annotation @PathVariable("regNo") @RequestParam("branch")
Express.js Property req.params.regNo req.query.branch

💻 Framework Implementation Snippets

Spring Boot REST Controller:

@RestController
@RequestMapping("/api/v1/students")
public class StudentController {

    // Path Variable: GET /api/v1/students/21B91A0501
    @GetMapping("/{regNo}")
    public Student getStudentByRegNo(@PathVariable("regNo") String regNo) {
        return studentService.findByRegNo(regNo);
    }

    // Request Parameters: GET /api/v1/students?branch=CSE&minGpa=8.5
    @GetMapping
    public List<Student> filterStudents(
            @RequestParam(name = "branch", required = false) String branch,
            @RequestParam(name = "minGpa", defaultValue = "0.0") Double minGpa) {
        return studentService.searchStudents(branch, minGpa);
    }
}

Express.js (Node.js):

const express = require('express');
const app = express();

// Path Variable: GET /students/21B91A0501
app.get('/students/:regNo', (req, res) => {
    const regNo = req.params.regNo; // Access path variable
    res.json({ regNo: regNo, name: "Ananya", branch: "CSE" });
});

// Request Parameters: GET /students?branch=CSE
app.get('/students', (req, res) => {
    const branch = req.query.branch; // Access query parameter
    res.json({ branch: branch, students: [] });
});
