🔤 URL Encoding & Decoding

Understanding Percent-Encoding in Web Requests and Query Strings

1. Why is URL Encoding Necessary?

URLs (Uniform Resource Locators) are transmitted over the Internet using the US-ASCII character set. Characters outside the standard ASCII set (like spaces, non-English symbols, or emojis) or characters with special reserved meanings in URLs (like ?, &, =, /, #) cannot be sent in raw format.

Percent-Encoding (URL Encoding) converts invalid or reserved characters into a % followed by a two-digit hexadecimal representation of their ASCII byte value.

📋 Common Reserved Characters & Encoded Equivalents

Character Character Name Percent-Encoded Value Purpose in URL
Space Space %20 or + Separates words in query values
? Question Mark %3F Starts the Query Parameter string
& Ampersand %26 Separates multiple query key-value pairs
= Equals Sign %3D Assigns value to a parameter key
/ Forward Slash %2F Separates URI path segments
# Hash / Anchor %23 Identifies a fragment/section in page
% Percent Sign %25 Escape character itself

💻 How Backends Handle URL Decoding

Modern frameworks handle URL decoding automatically, but understanding how to do it programmatically is vital:

Java Example:

import java.net.URLEncoder;
import java.net.URLDecoder;
import java.nio.charset.StandardCharsets;

public class UrlEncodingDemo {
    public static void main(String[] args) throws Exception {
        String originalText = "John Doe & Sons";
        
        // Encode
        String encoded = URLEncoder.encode(originalText, StandardCharsets.UTF_8);
        System.out.println("Encoded: " + encoded); // John+Doe+%26+Sons
        
        // Decode
        String decoded = URLDecoder.decode(encoded, StandardCharsets.UTF_8);
        System.out.println("Decoded: " + decoded); // John Doe & Sons
    }
}

JavaScript Example:

const original = "Java & Spring Boot?";

// Encode
const encoded = encodeURIComponent(original);
console.log(encoded); // "Java%20%26%20Spring%20Boot%3F"

// Decode
const decoded = decodeURIComponent(encoded);
console.log(decoded); // "Java & Spring Boot?"
