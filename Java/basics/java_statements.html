Java Statements, Expressions & Blocks

Understand the building blocks of Java program execution: declarations, expressions, control flow statements, and block scopes.

📜 1. What is a Java Statement?

In Java, a Statement is a complete unit of execution, analogous to a sentence in human language. Statements express an action to be performed and always terminate with a semicolon (;).

💡 Formula: Expression + Semicolon (;) = Statement!
🗂️ 2. Categories of Java Statements

Used to declare variables by specifying their data type and identifier name.

int score = 100; // Variable declaration & initialization
String username = "JP";
double price; // Uninitialized declaration

Statements formed by appending a semicolon to assignment, increment, method invocation, or object creation expressions.

count++; // Increment expression statement
total = price * quantity; // Assignment statement
System.out.println(total); // Method invocation statement
Scanner sc = new Scanner(System.in); // Object creation statement

Statements that control the execution order of code (decision making, looping, branching).

// Decision Making Statement
if (score >= 50) {
  System.out.println("Passed!");
}
// Looping Statement
for (int i = 0; i < 5; i++) { ... }

A group of zero or more statements enclosed in matching curly braces { } forming a block scope.

{ // Block Start
  int temp = 42; // Scoped inside block
  System.out.println(temp);
} // Block End (temp is out of scope here)
