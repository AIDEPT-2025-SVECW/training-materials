➕ Arithmetic & Modulus
Precedence: Level 3 & 4

Multiplicative (*, /, %) evaluate before Additive (+, -). Integer division truncates decimals.

int a = 10, b = 3;
int sum = a + b; // 13
int div = a / b; // 3 (decimals truncated!)
int mod = a % b; // 1 (remainder)
int res = 10 + 2 * 5; // 20 (NOT 60!)
⬆️ Pre vs Post Increment
Precedence: Level 1 & 2

Postfix (x++) has Level 1 precedence (evaluates value first). Prefix (++x) has Level 2 precedence (increments first).

int x = 5;
int y = ++x; // Pre: x becomes 6, y gets 6

int p = 5;
int q = p++; // Post: q gets 5, THEN p becomes 6
🤝 Relational & Equality
Precedence: Level 6 & 7

Relational (<, >=) has higher precedence than Equality (==, !=). All associate Left-to-Right.

boolean c1 = 5 > 3; // true
boolean c2 = 10 == 5 * 2; // true (* runs before ==)
boolean c3 = 5 > 3 == true; // (5 > 3) == true -> true
⚡ Logical AND / OR
Precedence: Level 11 & 12

Logical AND (&&) evaluates before Logical OR (||). Both short-circuit left-to-right.

boolean a = true, b = false, c = false;
boolean res = a || b && c; // true || (false && false) -> true!
boolean pass = (score >= 50) || (hasBonus);
⚙️ Bitwise & Bit-Shift
Precedence: Level 5, 8, 9, 10

Shift operators (<<, >>) execute before Bitwise (&, ^, |). Beware: addition runs before shift!

int p = 5 & 3; // 0101 & 0011 = 0001 (1)
int s = 1 << 2 + 1; // 1 << (2 + 1) = 1 << 3 = 8!
// Addition (+) executes BEFORE Shift (<<)
❓ Ternary & Assignment
Precedence: Level 13 & 14

Ternary (? :) and Assignment (=, +=) are Right-to-Left associative!

int a, b, c;
a = b = c = 10; // Right-to-left: a = (b = (c = 10))
String grade = score >= 90 ? "A" : score >= 80 ? "B" : "C";

🎯 Operator Precedence Self-Assessment Quizzes

1. What is the value of result?
int result = 10 + 5 * 2 - 4 / 2;
A) 13
B) 18
C) 23
🎉 Correct! Precedence rules: 5 * 2 = 10 and 4 / 2 = 2 run first. Then 10 + 10 - 2 = 18.
2. What are the values of a and b?
int a = 4; int b = a++ + ++a;
A) a = 6, b = 10
B) a = 6, b = 9
C) a = 5, b = 10
🎉 Correct! a++ uses original value 4 (then a becomes 5). Then ++a increments a to 6 and uses 6. b = 4 + 6 = 10.
3. What is printed by this code?
System.out.println("Java" + 10 + 20);
A) Java30
B) Java1020
C) Compilation Error
🎉 Correct! + evaluates Left-to-Right. "Java" + 10 yields "Java10", then "Java10" + 20 yields "Java1020".
4. What is the value of count after execution?
int count = 5;
boolean test = false && (++count > 0);
A) count = 5
B) count = 6
C) count = 0
🎉 Correct! Logical && short-circuits! Because the left-hand side is false, (++count > 0) is never evaluated, leaving count at 5.
