🏷️ 1. Standard Java Naming Conventions

Classes & Interfaces

PascalCase

Nouns beginning with an uppercase letter.

BankAccount, PaymentGateway

Variables & Methods

camelCase

Verbs or descriptive nouns starting lowercase.

calculateTax(), accountBalance

Constants

UPPER_SNAKE_CASE

All uppercase letters separated by underscores.

MAX_TIMEOUT_SECONDS, PI

Packages

lowercase

Reverse domain name notation in lowercase.

com.company.project.module
