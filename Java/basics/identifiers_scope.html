🎯 2. The 3 Types of Variable Scope

1. Local Scope

Declared inside a method or block. Created when method runs and destroyed upon method exit.

2. Instance Scope (Field)

Declared inside class but outside methods. Unique copy created for each Object instance on Heap.

3. Class / Static Scope

Declared with static keyword. Single shared copy stored in Metaspace across all objects.

public class Student {
  static String schoolName = "SVECW"; // Static Scope (Shared)
  int studentId; // Instance Scope (Per Object)

  public void process() {
    int count = 0; // Local Scope (Method frame only)
  }
}
Can a Java variable identifier start with a numeric digit (e.g. `2student`)?
A) Yes, if followed by letters
B) No, Java identifiers cannot start with a digit
C) Only in static variables
