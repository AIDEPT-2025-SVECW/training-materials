Typecasting in Java: Widening & Narrowing

Convert data types safely! Learn when Java automatically widens data types and how explicit narrowing casts larger values into smaller variables.

🔄 1. Implicit (Widening) vs Explicit (Narrowing) Casting

✅ Implicit Widening (Automatic)

Converts smaller data types into larger data types automatically without precision loss.

Path: byte ➔ short ➔ int ➔ long ➔ float ➔ double

int myInt = 9;
double myDouble = myInt; // Auto cast to 9.0

⚠️ Explicit Narrowing (Manual)

Converts larger data types into smaller types. Requires manual (target_type) cast and may cause data truncation or overflow.

double myDouble = 9.78;
int myInt = (int) myDouble; // Truncates decimal to 9
