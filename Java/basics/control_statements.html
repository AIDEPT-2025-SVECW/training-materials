Control Statements in Java

Expressions & Decision Making Switch Expressions Loops & Big O Complexity Live Execution Simulators

Control statements dictate the flow of program execution based on conditions and repetitions. Master conditional branching (if, switch), loops (for, while, do-while), and jump statements (break, continue).

💡 What is an Expression in Java?

An Expression is a combination of variables, literals, operators, and method calls that Java evaluates to produce a single result value.

1. Arithmetic Expression
Evaluates to Number

Combines numbers & arithmetic operators.

int result = 10 + 5 * 2; // Evaluates to 20
2. Relational Expression
Evaluates to boolean

Compares values using relational operators.

boolean isAdult = age >= 18; // true or false
3. Expression Statement
Statement ending with ;

An expression converted to a standalone statement.

count++; // Expression statement
System.out.println("Hello"); // Statement
🌿 Conditional Decision Making Statements
Simple `if` Statement
Single Branch

Executes code block ONLY if boolean condition evaluates to true.

if (score >= 50) {
  System.out.println("You passed!");
}
`if-else` Statement
Two Branches

Executes `if` block if `true`, otherwise executes `else` block.

if (num % 2 == 0) {
  System.out.println("Even");
} else {
  System.out.println("Odd");
}
`if-else-if` Ladder
Multiple Branches

Tests multiple conditions sequentially until one evaluates to `true`.

if (marks >= 90) grade = "A";
else if (marks >= 75) grade = "B";
else grade = "C";
Nested `if` Statement
Condition inside Condition

An `if` statement placed inside another `if` block.

if (hasId) {
  if (age >= 18) {
    System.out.println("Allowed");
  }
}
Ternary Operator (`? :`)
Inline Conditional

Shorthand inline conditional expression: (condition) ? trueVal : falseVal.

int max = (a > b) ? a : b;
String status = (age >= 18) ? "Adult" : "Minor";
🔀 Switch Statements in Java (Traditional & Modern)

The switch statement tests a variable against a list of values (called cases). Java supports primitives (byte, short, char, int), String, and enums.

1. Traditional Switch Statement
Classic Java

Requires explicit break to prevent fall-through into subsequent cases.

int day = 2;
switch (day) {
  case 1:
    System.out.println("Mon");
    break;
  case 2:
    System.out.println("Tue");
    break;
  default:
    System.out.println("Other");
}
2. Modern Arrow Switch Expression (Java 14+)
No Fall-Through!

Uses -> arrow syntax. Returns a value directly with no break statements needed!

String dayName = switch (day) {
  case 1 -> "Monday";
  case 2 -> "Tuesday";
  case 6, 7 -> "Weekend";
  default -> "Invalid";
};
🔄 Iteration Loops (`for`, `while`, `do-while`, `for-each`)
1. Standard `for` Loop
Definite Count

Best when the exact number of iterations is known beforehand.

for (int i = 1; i <= 5; i++) {
  System.out.println("Count: " + i);
}
2. `while` Loop
Pre-Test Loop

Checks condition BEFORE executing loop body (0 or more executions).

int count = 1;
while (count <= 3) {
  System.out.println(count);
  count++;
}
3. `do-while` Loop
Post-Test (Min 1 Run)

Executes body FIRST, then checks condition. Guaranteed to run at least ONCE!

int x = 10;
do {
  System.out.println("Runs at least once!");
} while (x < 5);
4. Enhanced `for-each` Loop
Arrays & Collections

Iterates seamlessly over array or collection elements without index tracking.

int[] nums = {10, 20, 30};
for (int n : nums) {
  System.out.println(n);
}
5. Nested `for` Loop
Grid / Matrix Processing

A loop inside another loop body (useful for 2D arrays & patterns).

for (int r = 1; r <= 3; r++) {
  for (int c = 1; c <= 3; c++) {
    System.out.print("*");
  }
}
🧠 Mind Twister Questions & Loop Time Complexity (Big O)

Test your deep understanding of loop execution edge cases and analyze Big O Time Complexity for single and nested loops!

🧠 1. The Byte Overflow Trap
Edge Case

Will this loop run infinitely or terminate?

for (byte b = 0; b >= 0; b++) {
  System.out.println(b);
}
💡 Reveal Answer & Explanation
Answer: It will eventually terminate!
Why? In Java, a byte has 8 bits (range -128 to 127). When b reaches 127, incrementing 127 + 1 causes a signed integer overflow to -128. Since -128 >= 0 evaluates to false, the loop terminates cleanly after 128 iterations!
⚡ 2. Logarithmic Loop Complexity
O(log N)

What is the Big O time complexity when doubling loop step?

for (int i = 1; i <= n; i *= 2) {
  // O(1) operation
}
💡 Reveal Big O Analysis
Time Complexity: O(log₂ N)
Why? Instead of incrementing by 1, i doubles each cycle (1, 2, 4, 8, 16, ..., 2^k). The loop stops when 2^k > n, which means k = log₂ n iterations.
📊 3. Nested Loops Time Complexity
O(N²) & O(N × M)

How do nested loops multiply time complexity?

for (int i = 0; i < N; i++) {
  for (int j = 0; j < N; j++) {
    // Executed N * N times!
  }
}
💡 Reveal Big O Nested Analysis
1. Independent NxN Bounds: Outer loop runs N times. For every outer iteration, inner loop runs N times. Total operations = N × N = N² → O(N²) (Quadratic Time).

2. Dependent Inner Loop (Triangular):
for(int j = 0; j <= i; j++) → Total runs: 1 + 2 + 3 + ... + N = N(N+1)/2 = (N²+N)/2. Dropping lower terms gives O(N²).

3. Different Dimensions (N & M): Outer runs N times, inner runs M times → O(N × M).
⚡ Jump Statements & Variable Block Scope
1. `break` Statement
Loop / Switch Exit

Immediately terminates the loop or switch block.

for (int i = 1; i <= 10; i++) {
  if (i == 5) break; // Stop loop
  System.out.println(i);
}
2. `continue` Statement
Skip Iteration

Skips remaining code in current iteration and jumps to next iteration cycle.

for (int i = 1; i <= 5; i++) {
  if (i == 3) continue; // Skip 3
  System.out.println(i);
}
3. Labeled `break` & `continue`
Outer Loop Jumps

Controls outer loops directly from inside inner nested loops.

outerLoop:
for (int i = 1; i <= 3; i++) {
  for (int j = 1; j <= 3; j++) {
    if (i * j > 4) break outerLoop;
  }
}
4. Variable Scope in Control Blocks
Block Scope Rule

Variables declared inside `{ }` control blocks exist ONLY within that block.

if (true) {
  int temp = 100; // Local to block
}
// temp is NOT accessible here!

🎯 Control Statements Self-Assessment Quizzes

Test your mastery of Java conditional branching, switch behavior, loops, and jump statements!

1. Which loop is guaranteed to execute at least ONCE regardless of condition?
A) for loop
B) while loop
C) do-while loop
🎉 Correct! do-while is a post-test loop. It executes the body first before evaluating the condition!
2. What happens if a traditional switch case omits the `break` statement?
A) Compilation Error
B) Fall-through into subsequent cases
C) Loop repeats indefinitely
🎉 Correct! Omitted break causes "fall-through" execution into subsequent case blocks until a break or end of switch is hit.
3. What is printed by this loop?
for(int i = 1; i <= 5; i++) {
  if(i == 3) continue;
  System.out.print(i + " ");
}
A) 1 2
B) 1 2 4 5
C) 1 2 3 4 5
🎉 Correct! When i == 3, continue skips the print statement and jumps to i++.
4. What is the value of `result`?
int x = 10;
int result = (x > 15) ? 100 : (x > 5) ? 200 : 300;
A) 100
B) 200
C) 300
🎉 Correct! x > 15 is false, so it evaluates the false branch: (x > 5) ? 200 : 300. Since 10 > 5 is true, it yields 200.
