Comments & Javadoc Documentation in Java

Write clean, maintainable, and self-documenting Java code using Single-Line, Multi-Line, and official Javadoc comments.

💬 1. The 3 Types of Java Comments

1. Single-Line Comment

Begins with //. Everything following on that line is ignored by javac compiler.

// Calculate total price with 10% tax
double total = price * 1.10;

2. Multi-Line Comment

Enclosed between /* and */. Spans across multiple lines for longer notes.

/*
 * Temporary workaround for legacy
 * payment API timeout issue.
 */

3. Javadoc Comment

Enclosed between /** and */. Used to generate official HTML documentation pages.

/**
 * Calculates customer discount.
 * @param amount purchase total
 * @return final discounted price
 */
