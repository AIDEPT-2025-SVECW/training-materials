Command Line Interface & Arguments in Java

Master CLI inputs! Learn how Java receives external launch parameters into String[] args and parses inputs dynamically.

🖥️ 1. What is Command Line Interface (CLI)?

The Command Line Interface (CLI) allows developers and systems to interact with Java applications by typing commands into terminal windows (Cmd, PowerShell, Terminal) instead of clicking buttons in a GUI.

When starting a Java app, inputs passed after the class name are captured inside the String[] args array of the main method.

📜 3. Reading & Parsing Command Line Arguments in Code
public class App {
  public static void main(String[] args) {
    if (args.length < 2) {
      System.out.println("Usage: java App <name> <age>");
      return;
    }
    String name = args[0];
    int age = Integer.parseInt(args[1]); // Convert String to int
    System.out.println("User: " + name + ", Age: " + age);
  }
}
