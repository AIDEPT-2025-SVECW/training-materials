Java Entry Point & CLI Execution

`public static void main` `String[] args` `javac` Compiler `java` Launcher CLI Terminal Simulator

Understand the exact starting point of any Java application: public static void main(String[] args). Explore why each keyword is required by the JVM runtime and master compiling and launching Java applications from the command line interface.

🔍 Anatomy of `public static void main(String[] args)`

When you execute a Java program, the JVM launcher looks specifically for a method with the signature public static void main(String[] args) as the entry point. Every keyword serves a distinct purpose:

public class HelloWorld {
  // Universal Application Entry Point
  public static void main(String[] args) {
    System.out.println("Hello, Java World!");
  }
}
1. `public`
Access Modifier

Specifies that the main() method is accessible from anywhere outside the package. The JVM runtime launcher resides outside your application package and requires public access to invoke it.

2. `static`
Class Modifier

Allows the JVM to invoke main() directly on the class (HelloWorld.main()) without instantiating an object first (`new HelloWorld()`).

3. `void`
Return Type

Indicates that main() returns no value back to the OS. When main() finishes execution, the application process terminates cleanly with exit code 0.

4. `main`
Method Name

The standardized method name hardcoded in the JVM launcher specification as the entry point signature.

5. `String[] args`
Parameter Array

An array of String parameters holding any command-line arguments passed when launching the program from terminal (e.g. java HelloWorld arg1 arg2).

💻 Command Line Execution (`javac` vs `java`)

Executing a Java application from the Command Line Interface (CLI) involves a two-stage process: Compilation followed by JVM Launching.

Stage 1: Compilation (`javac`)
javac Compiler

Compiles human-readable Java source code (.java) into platform-independent JVM Bytecode (.class file).

$ javac HelloWorld.java
# Generates HelloWorld.class
Stage 2: Execution (`java`)
java JVM Launcher

Starts the JVM runtime, loads the .class bytecode, finds public static void main, and interprets/JIT-executes it!

$ java HelloWorld
Hello, Java World!
Comparison Tool javac (Java Compiler) java (JVM Launcher)
Purpose Translates source code to bytecode Executes bytecode on JVM runtime
Input File HelloWorld.java (Must include .java extension) HelloWorld (Class name WITHOUT .class extension)
Output Creates HelloWorld.class bytecode file Executes main() and outputs terminal result
Errors Reported Syntax and Compile-Time errors Runtime Exceptions (e.g. NullPointerException)
💡 Modern Java 11+ Single-File Direct Execution
Since Java 11, for single-file source files you can run java HelloWorld.java directly in terminal! The JVM automatically compiles it in memory and executes it without generating a physical .class file on disk.
📦 Command-Line Arguments (`String[] args`)

Passing Arguments at Startup

When launching a program via java Greeter Alice Bob Developer, the JVM captures space-separated text arguments and populates the String[] args array:

  • args[0] = "Alice"
  • args[1] = "Bob"
  • args[2] = "Developer"
  • args.length = 3
⚠️ Handling Missing Arguments Safely
Accessing args[0] when no CLI arguments were passed throws java.lang.ArrayIndexOutOfBoundsException. Always check if (args.length > 0) before accessing array indices!
// Greeter.java — Reading Command Line Inputs
public class Greeter {
  public static void main(String[] args) {
    // Safely check array length
    if (args.length < 2) {
      System.out.println("Usage: java Greeter ");
      return;
    }

    String name = args[0];
    // Convert String argument to primitive int
    int age = Integer.parseInt(args[1]);

    System.out.println("Hello " + name + "! You are " + age + " years old.");
  }
}

🎯 Java Entry Point & CLI Self-Assessment Quizzes
1. Why must the main method in Java be declared as `static`?
A) To allow JVM to invoke it without instantiating an object first
B) To make variables inside main immutable
C) To prevent other classes from calling main
🎉 Correct! static allows the JVM runtime launcher to call ClassName.main() directly without allocating an object instance in Heap memory.
2. What command compiles a `HelloWorld.java` source file into bytecode?
A) java HelloWorld.java
B) javac HelloWorld.java
C) compile HelloWorld
🎉 Correct! The javac command compiles source code files (which require the .java file extension) into .class bytecode.
3. How do you launch a compiled Java class `HelloWorld.class` using JVM?
A) java HelloWorld.class
B) java HelloWorld
C) run HelloWorld
🎉 Correct! The java command accepts the class name WITHOUT the .class file extension.
4. If you run `java App Alice 25`, what is stored in `args[0]`?
A) "App"
B) "Alice"
C) "25"
🎉 Correct! In Java (unlike C/C++), index args[0] contains the first command-line argument passed after the class name (i.e. "Alice").
