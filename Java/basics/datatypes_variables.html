Data Types & Variables in Java

Learn how values are stored in memory! Explore Java's 8 primitive data types, variable declarations, default values, and reference types.

📦 1. What is a Variable? (Declaration vs Initialization)

A Variable is a named container in memory used to store data values during program execution.

// 1. Variable Declaration (Reserves memory type)
int age;

// 2. Variable Initialization (Assigns initial value)
age = 25;

// 3. Combined Declaration & Initialization
double salary = 75000.50;
