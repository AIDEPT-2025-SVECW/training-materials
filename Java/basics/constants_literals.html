Literal Constants & Symbolic Constants in Java

Understand fixed literal values (Integer, Float, Character, String) and declare immutable symbolic constants using the final keyword.

💎 1. What are Literal Constants?

A Literal is a fixed value written directly into source code without requiring computation.

Integer Literals

Decimal: 100
Binary prefix 0b: 0b1010 (10)
Hex prefix 0x: 0x1F (31)

Floating-Point Literals

Double default: 3.14159
Float suffix f: 3.14f
Long suffix L: 1000000000L

Char & String Literals

Char single quotes: 'A', '\n'
String double quotes: "Java"

Boolean & Null Literals

Boolean: true, false
Reference null: null

🔒 2. Symbolic Constants (`final` Keyword)

A Symbolic Constant is a named variable declared with the final keyword whose value cannot be changed once assigned.

public class Circle {
  public static final double PI = 3.14159265359; // Symbolic Constant
  public static final int MAX_USERS = 500;

  public void update() {
    // PI = 3.14; // ❌ COMPILER ERROR: Cannot assign value to final variable!
  }
}
