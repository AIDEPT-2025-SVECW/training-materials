Methods for Extracting Characters & Searching Strings

Learn how to slice, parse, inspect, and search text in Java: charAt(), substring(), indexOf(), contains(), startsWith(), and endsWith() using real-world IRCTC, UPI, and Indian mobile validations.

charAt & toCharArray substring(begin, end) indexOf & lastIndexOf startsWith & endsWith contains & isEmpty
✂️

1. Methods for Extracting Characters from Strings

Strings in Java are zero-indexed: the first character is at index 0 and the last character is at index length() - 1.

Method Signature Return Type Description & Behavior Example (Input: "IRCTC-PNR")
charAt(int index) char Returns the character at specified index. Throws StringIndexOutOfBoundsException if index < 0 or >= length. s.charAt(0) → 'I'
substring(int beginIndex) String Returns substring from beginIndex all the way to the end of the string. s.substring(6) → "PNR"
substring(int begin, int end) String Returns substring from beginIndex (inclusive) up to endIndex (exclusive). Length = end - begin. s.substring(0, 5) → "IRCTC"
toCharArray() char[] Converts the string into a brand new character array for in-place array manipulation. {'I','R','C','T','C','-','P','N','R'}
subSequence(int begin, int end) CharSequence Defined by CharSequence interface; identical to substring but returns a CharSequence reference. s.subSequence(0, 5) → "IRCTC"
⚠️
The Golden Rule of substring(beginIndex, endIndex):
In Java, endIndex is EXCLUSIVE! That means the character at endIndex is NOT included in the extracted result.
Formula: Length of extracted string = endIndex - beginIndex.
For example, "BHARAT".substring(0, 3) extracts indices 0, 1, 2 → "BHA" (length = 3 - 0 = 3).
🔍

2. Methods for Searching & Inspecting Strings

Java provides intuitive methods to search for single characters, substrings, prefixes, and suffixes:

Method Signature Return Type Description Key Nuance / Edge Case
indexOf(String str) int Returns the index of the first occurrence of substring. Returns -1 if the substring is not found!
indexOf(String str, int fromIndex) int Searches forward starting from fromIndex onwards. Useful for finding multiple occurrences in a loop.
lastIndexOf(String str) int Returns index of the last occurrence of substring. Searches backwards from the end towards index 0.
contains(CharSequence s) boolean Returns true if the exact character sequence exists anywhere. Case-sensitive! "UPI".contains("upi") is false.
startsWith(String prefix) boolean Returns true if string begins with specified prefix. Perfect for checking +91 mobile codes or PIN codes.
endsWith(String suffix) boolean Returns true if string ends with specified suffix. Ideal for validating file extensions (.csv) or UPI handles (@ybl).
isEmpty() vs isBlank() boolean isEmpty() checks if length() == 0. isBlank() (Java 11+) checks if string is empty OR contains only whitespace! " ".isEmpty() → false
" ".isBlank() → true

3. Runnable Program: IRCTC SMS Parser & UPI Validator

The following self-contained program demonstrates extracting booking information from an IRCTC train SMS and validating Indian mobile & UPI payment handles:

StringExtractAndSearchDemo.java
/**
 * Topic: Extracting Characters & Searching Strings in Java
 * Real-World Context: IRCTC SMS Ticket Parsing & UPI Handle Verification
 */
public class StringExtractAndSearchDemo {

    public static void main(String[] args) {
        System.out.println("==================================================");
        System.out.println("  SCENARIO 1: PARSING IRCTC TICKET SMS MESSAGE   ");
        System.out.println("==================================================");

        String irctcMsg = "IRCTC: PNR 4528190342 | Trn 12723 Telangana Exp | B1-42 (CNF)";
        System.out.println("Raw SMS: " + irctcMsg);

        // 1. Extract PNR number using indexOf and substring
        String pnrKeyword = "PNR ";
        int pnrStart = irctcMsg.indexOf(pnrKeyword) + pnrKeyword.length();
        int pnrEnd = irctcMsg.indexOf(" |", pnrStart);
        String pnr = irctcMsg.substring(pnrStart, pnrEnd);
        System.out.println("Extracted 10-Digit PNR : [" + pnr + "]");

        // 2. Extract Train Number using charAt & substring
        int trnIndex = irctcMsg.indexOf("Trn ") + 4;
        String trainNumber = irctcMsg.substring(trnIndex, trnIndex + 5);
        System.out.println("Extracted Train Number  : [" + trainNumber + "]");

        // 3. Extract Coach & Berth status
        int lastPipe = irctcMsg.lastIndexOf("|");
        String berthDetails = irctcMsg.substring(lastPipe + 2);
        System.out.println("Berth & Status Info    : [" + berthDetails + "]");

        // 4. Converting to char[] to count digits
        char[] chars = pnr.toCharArray();
        System.out.print("PNR Individual Digits  : ");
        for (char ch : chars) {
            System.out.print(ch + " ");
        }
        System.out.println();

        System.out.println("\n==================================================");
        System.out.println("  SCENARIO 2: INDIAN MOBILE & UPI VALIDATIONS     ");
        System.out.println("==================================================");

        String phone1 = "+919876543210";
        String phone2 = "09876543210";
        String phone3 = "1234567890";

        validateIndianPhone(phone1);
        validateIndianPhone(phone2);
        validateIndianPhone(phone3);

        System.out.println("\n--- UPI Payment VPA Validation ---");
        String upi1 = "ananya.sharma@oksbi";
        String upi2 = "swiggy.orders@icici";
        String upi3 = "invalid_user_address";

        validateUpiId(upi1);
        validateUpiId(upi2);
        validateUpiId(upi3);
    }

    private static void validateIndianPhone(String phone) {
        if (phone.startsWith("+91")) {
            System.out.println("[VALID] " + phone + " has standard +91 Indian country code.");
        } else if (phone.startsWith("0")) {
            System.out.println("[VALID] " + phone + " has domestic STD trunk 0 prefix.");
        } else {
            System.out.println("[WARNING] " + phone + " missing Indian code (+91 or 0).");
        }
    }

    private static void validateUpiId(String vpa) {
        if (vpa.contains("@") && (vpa.endsWith("@oksbi") || vpa.endsWith("@icici") || vpa.endsWith("@paytm"))) {
            int atIndex = vpa.indexOf("@");
            String username = vpa.substring(0, atIndex);
            String bankHandle = vpa.substring(atIndex);
            System.out.println("[SUCCESS] Valid VPA: User='" + username + "', Bank Handle='" + bankHandle + "'");
        } else {
            System.out.println("[REJECTED] Invalid VPA: '" + vpa + "' missing '@' or recognized bank PSP handle.");
        }
    }
}

📌 Key Takeaways for Freshers

  • Zero-Indexed: First char is at index 0; last char is at length() - 1.
  • Exclusive End: substring(start, end) stops right before index end.
  • Searching Misses: indexOf() and lastIndexOf() return -1 if target text is absent. Always check != -1 before slicing with substring()!
  • Prefix & Suffix: Use startsWith() and endsWith() instead of manual index math for clean, readable code.
  • Java 11 Tip: Use isBlank() instead of isEmpty() when validating user form inputs to catch strings containing only spaces (e.g. " ").
