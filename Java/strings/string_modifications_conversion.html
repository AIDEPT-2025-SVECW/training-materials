1. Methods for Modifying Strings (Remember Immutability!)

Because String objects are immutable in Java, none of these methods alter the original string. Instead, they compute the change and return a brand new String object. Always remember to capture the return value!

Method Signature Return Type What It Does Indian Real-World Context
concat(String str) String Appends str to the end (equivalent to + operator). Appending state suffix: "Kolkata".concat(", WB")
replace(char old, char new) String Replaces all occurrences of an old character with a new one. Replacing hyphens with slashes in dates: "15-08-1947" → "15/08/1947"
replace(CharSequence target, CharSequence replacement) String Replaces exact target substring literal with replacement substring. Normalizing city spellings: replacing "Bangalore" with "Bengaluru"
replaceAll(String regex, String replacement) String Replaces all substrings matching a Regular Expression (regex). Masking Indian Aadhaar numbers: "1234 5678 9012" → "XXXX-XXXX-9012"
toLowerCase() / toUpperCase() String Converts all characters to lower or upper case based on locale. Normalizing Indian PAN card characters: "abcde1234f".toUpperCase()
trim() vs strip() String Removes leading and trailing whitespace. (strip() is Java 11+ and handles Unicode spaces). Cleaning up noisy mobile user input during OTP form submission.
🛠️

2. Data Conversion, Splitting, Joining & Formatting

These static and instance utility methods are used extensively in enterprise web services, API controllers, and CSV data pipelines:

Method Signature Type Description & Behavior Production Advantage
String.valueOf(anyPrimitiveOrObject) static String Converts int, double, boolean, or Object into a String. Null-Safe! If object is null, returns "null" string instead of throwing NullPointerException.
split(String regex) String[] Splits this string around matches of the given regular expression delimiter. Standard method for parsing CSV rows, Swiggy order receipts, and tab-separated logs.
String.join(CharSequence delim, CharSequence... elements) static String Joins elements together using specified delimiter (Java 8+). Eliminates tedious manual loops and trailing comma cleanup when assembling addresses.
String.format(String format, Object... args) static String Produces formatted strings using printf-style placeholders (%s, %d, %,.2f). Formats Indian Rupee prices (e.g. ₹1,25,000.50) and zero-padded order IDs.

3. Runnable Program: Swiggy CSV Parser, Aadhaar Masker & Rupee Receipt

The following self-contained program demonstrates CSV parsing with split(), address joining with String.join(), Aadhaar masking with replaceAll(), and currency formatting with String.format():

StringModifyAndConversionDemo.java
/**
 * Topic: String Modifications, Data Conversion, split, join, and format
 * Real-World Context: Swiggy Order CSV Parsing, Aadhaar Masking & Rupee Receipt
 */
public class StringModifyAndConversionDemo {

    public static void main(String[] args) {
        System.out.println("==================================================");
        System.out.println("  SCENARIO 1: PARSING SWIGGY ORDER CSV RECORD     ");
        System.out.println("==================================================");

        // Raw CSV line: OrderID, Customer, Item, Quantity, Price, PaymentMode
        String csvRecord = "SWIG-9402,Ananya Sharma,Hyderabadi Chicken Biryani,2,340.0,UPI";
        System.out.println("Raw CSV Line: " + csvRecord);

        // Tokenizing using split(",")
        String[] tokens = csvRecord.split(",");
        String orderId = tokens[0];
        String customerName = tokens[1];
        String item = tokens[2];
        int qty = Integer.parseInt(tokens[3]);
        double unitPrice = Double.parseDouble(tokens[4]);
        String paymentMode = tokens[5];

        double totalBill = qty * unitPrice;

        // Printing formatted invoice receipt using String.format:
        System.out.println("\n--- Swiggy Invoice Slip ---");
        System.out.println(String.format("Order Ref    : %s", orderId));
        System.out.println(String.format("Customer     : %s", customerName));
        System.out.println(String.format("Item Ordered : %s (Qty: %d)", item, qty));
        System.out.println(String.format("Total Amount : Rs. %,.2f (Paid via %s)", totalBill, paymentMode));

        System.out.println("\n==================================================");
        System.out.println("  SCENARIO 2: JOINING INDIAN ADDRESS TOKENS       ");
        System.out.println("==================================================");

        // Assembling structured Indian address without trailing comma headaches:
        String deliveryAddress = String.join(", ", 
            "Flat 402, Sri Sai Nilayam", 
            "Road No. 12, Banjara Hills", 
            "Hyderabad", 
            "Telangana", 
            "500034"
        );
        System.out.println("Assembled Delivery Address:\n" + deliveryAddress);

        System.out.println("\n==================================================");
        System.out.println("  SCENARIO 3: AADHAAR MASKING (replaceAll & regex)");
        System.out.println("==================================================");

        // Masking first 8 digits of 12-digit Aadhaar for privacy & compliance
        String rawAadhaar = "5489 2014 9876";
        // Regex: replace first 8 digits with 'XXXX XXXX '
        String maskedAadhaar = rawAadhaar.replaceAll("^\\d{4} \\d{4}", "XXXX XXXX");

        System.out.println("Original Aadhaar Number : " + rawAadhaar);
        System.out.println("Masked Aadhaar for UI   : " + maskedAadhaar);

        System.out.println("\n==================================================");
        System.out.println("  SCENARIO 4: NULL-SAFE String.valueOf()          ");
        System.out.println("==================================================");

        Object nullableCoupon = null;
        // nullableCoupon.toString() would crash with NullPointerException!
        String safeCouponStr = String.valueOf(nullableCoupon);
        System.out.println("String.valueOf(null) safely returned : \"" + safeCouponStr + "\"");
    }
}

📌 Key Takeaways for Freshers

  • Immutability trap: Calling str.replace("a", "b") does NOT alter str. Always assign the returned value: str = str.replace("a", "b");.
  • CSV Parsing: split(",") returns an array of tokens. Be aware that split takes a regular expression (escape special characters like \\. or \\|).
  • Clean Joining: Use String.join(", ", array) to assemble lists without manual loops and unwanted trailing commas.
  • Formatted Currency: Use String.format("Rs. %,.2f", amount) for clean comma separation and 2 decimal points in financial calculations.
  • Null Safety: Prefer String.valueOf(obj) over obj.toString() to protect against NullPointerException.
