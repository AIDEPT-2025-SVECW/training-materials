Activity 1: Indian Citizen Data Sanitizer & Masker

Requirement: Write a program that takes raw citizen input:

  • Clean up leading/trailing spaces using trim() or strip().
  • Mask the first 8 digits of a 12-digit Aadhaar number with "XXXX-XXXX-", keeping only the final 4 digits visible.
  • Capitalize the 10-character PAN card string (e.g. "abcde1234f" → "ABCDE1234F").
  • Validate that the citizen's mobile number starts with +91.

CitizenDataSanitizerSolution.java
public class CitizenDataSanitizerSolution {
    public static void main(String[] args) {
        String rawAadhaar = "  4829 1049 8492  ";
        String rawPan = "  bpzpk1024m  ";
        String rawMobile = "+919876543210";

        // 1. Clean input strings:
        String cleanAadhaar = rawAadhaar.trim();
        String cleanPan = rawPan.trim().toUpperCase();
        String cleanMobile = rawMobile.trim();

        // 2. Mask Aadhaar:
        String lastFour = cleanAadhaar.substring(cleanAadhaar.length() - 4);
        String maskedAadhaar = "XXXX-XXXX-" + lastFour;

        // 3. Mobile Check:
        boolean hasValidCountryCode = cleanMobile.startsWith("+91");

        // Print Summary:
        System.out.println("Sanitized PAN     : " + cleanPan);
        System.out.println("Masked Aadhaar    : " + maskedAadhaar);
        System.out.println("Valid +91 Mobile? : " + hasValidCountryCode);
    }
}

Activity 2: IRCTC SMS Ticket Parser

Requirement: An SMS gateway delivers ticket confirmations as a single pipe-delimited text line:
"PNR:6549281034|TRAIN:12723|ROUTE:HYB-NDLS|SEAT:B2-19|AMT:1850.00"

  • Use split("\\|") to break the line into individual key-value tokens.
  • Extract the 10-digit PNR number, train code, seat berth, and fare.
  • Use StringBuilder to assemble and format an IRCTC Journey Ticket Card.

IrctcPnrExtractorSolution.java
public class IrctcPnrExtractorSolution {
    public static void main(String[] args) {
        String sms = "PNR:6549281034|TRAIN:12723|ROUTE:HYB-NDLS|SEAT:B2-19|AMT:1850.00";

        // Split by pipe '|' (escaped as \\| because pipe is regex OR operator):
        String[] parts = sms.split("\\|");

        StringBuilder ticketCard = new StringBuilder();
        ticketCard.append("======================================\n")
                  .append("         IRCTC E-TICKET CARD          \n")
                  .append("======================================\n");

        for (String part : parts) {
            String[] kv = part.split(":");
            ticketCard.append(String.format("%-12s : %s\n", kv[0], kv[1]));
        }
        ticketCard.append("======================================\n");

        System.out.println(ticketCard.toString());
    }
}
