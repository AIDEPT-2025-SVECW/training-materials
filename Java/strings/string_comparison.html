Methods for Comparison of Strings & Sorting

Crush the #1 Java interview question: the profound difference between == and .equals(), case-insensitive comparison, compareTo() for alphabetical sorting, and contentEquals().

== vs .equals() equalsIgnoreCase() compareTo() & Sorting contentEquals()
⚖️

1. The #1 Interview Question: == vs .equals()

The most common bug committed by freshers in Java is comparing two Strings using the == operator instead of the .equals() method.

The == Operator (Reference Equality)

Tests whether both reference variables point to the exact same memory address in RAM. 

String a = new String("Pune");
String b = new String("Pune");
a == b; // FALSE! Different memory addresses!

The .equals() Method (Content Equality)

Overridden in String to test whether both objects contain the exact same characters in the same order. 

String a = new String("Pune");
String b = new String("Pune");
a.equals(b); // TRUE! Both have characters 'P','u','n','e'
🚨
Banking Production Nightmare:
If you write if (enteredOtp == systemOtp) in an Indian NetBanking or UPI service, the condition will evaluate to false whenever enteredOtp is parsed from a network HTTP request (created on the general heap), locking out legitimate customers! Always use systemOtp.equals(enteredOtp).
📊

2. Complete String Comparison Methods Suite

Method Signature Return Type How It Compares Indian Real-World Scenario
equals(Object another) boolean Strict case-sensitive character-by-character match. Verifying case-sensitive credentials (e.g. NetBanking passwords).
equalsIgnoreCase(String str) boolean Case-insensitive match (ignores uppercase vs lowercase). Swiggy/Zomato delivery city search: "Bengaluru" matches "bengaluru".
compareTo(String another) int Lexicographical comparison (Unicode ASCII difference of first mismatching char). Sorting Indian student names alphabetically for college roll-call registers.
compareToIgnoreCase(String str) int Lexicographical comparison ignoring case distinctions. Sorting dictionary or contact names regardless of capitalization.
contentEquals(CharSequence cs) boolean Compares String against any CharSequence (like StringBuffer or StringBuilder). Validating a mutable buffer without needing expensive .toString() conversion!
💡
Understanding compareTo() Return Values:
  • 0: Both strings are identical ("Delhi".compareTo("Delhi") == 0).
  • Negative (< 0): Current string comes before the argument alphabetically ("Aarav".compareTo("Vikram") < 0).
  • Positive (> 0): Current string comes after the argument alphabetically ("Zara".compareTo("Rohan") > 0).

3. Runnable Program: OTP Verification & Alphabetical Student Roll-Call

The following self-contained program demonstrates equals() vs ==, case-insensitive delivery search, and sorting an array of Indian student names using compareTo():

StringComparisonAndSortingDemo.java
/**
 * Topic: String Comparison Methods, == vs .equals(), and Lexicographical Sorting
 * Real-World Context: Indian NetBanking OTP & College Student Roll-Call Sorting
 */
public class StringComparisonAndSortingDemo {

    public static void main(String[] args) {
        System.out.println("==================================================");
        System.out.println("  SCENARIO 1: == vs .equals() (NETBANKING OTP)    ");
        System.out.println("==================================================");

        // Server generated OTP in memory:
        String serverOtp = "849201";

        // Customer enters OTP through mobile app (parsed into new Heap object):
        String userOtp = new String("849201");

        // Danger of ==
        System.out.println("Using == operator       : " + (serverOtp == userOtp)); // false!
        if (serverOtp == userOtp) {
            System.out.println("Transaction Approved (==)");
        } else {
            System.out.println("[BUGGY REJECTION] serverOtp == userOtp failed due to memory address difference!");
        }

        // Correct way using .equals()
        System.out.println("Using .equals() method  : " + serverOtp.equals(userOtp)); // true!
        if (serverOtp.equals(userOtp)) {
            System.out.println("[SUCCESS] OTP Verified via .equals()! Payment of Rs. 4,500 Authorized.");
        }

        System.out.println("\n==================================================");
        System.out.println("  SCENARIO 2: CASE-INSENSITIVE CITY MATCHING      ");
        System.out.println("==================================================");

        String registeredCity = "Hyderabad";
        String userSearchInput = "hyderabad";

        System.out.println("Strict equals()         : " + registeredCity.equals(userSearchInput));          // false
        System.out.println("equalsIgnoreCase()      : " + registeredCity.equalsIgnoreCase(userSearchInput));// true

        // contentEquals with StringBuilder:
        StringBuilder dynamicBuffer = new StringBuilder("Hyderabad");
        System.out.println("contentEquals(StringBuilder) : " + registeredCity.contentEquals(dynamicBuffer)); // true

        System.out.println("\n==================================================");
        System.out.println("  SCENARIO 3: SORTING STUDENT NAMES (compareTo)   ");
        System.out.println("==================================================");

        String[] students = { "Vikram Reddy", "Ananya Sharma", "Deepak Verma", "Bhavna Patel", "Aditi Rao" };

        System.out.println("Before Sorting (Unordered Admissions):");
        for (String s : students) System.out.println(" - " + s);

        // Bubble Sort using compareTo to arrange alphabetically:
        for (int i = 0; i < students.length - 1; i++) {
            for (int j = 0; j < students.length - 1 - i; j++) {
                // If students[j] comes alphabetically AFTER students[j+1], swap them!
                if (students[j].compareTo(students[j + 1]) > 0) {
                    String temp = students[j];
                    students[j] = students[j + 1];
                    students[j + 1] = temp;
                }
            }
        }

        System.out.println("\nAfter Sorting (Alphabetical Class Roll-Call Register):");
        for (int i = 0; i < students.length; i++) {
            System.out.println(" Roll No " + (i + 1) + ": " + students[i]);
        }
    }
}

📌 Key Takeaways for Freshers

  • Golden Rule: Always compare String values using .equals(), never ==.
  • Case-Tolerance: Use equalsIgnoreCase() for user-entered usernames, cities, email domains, and coupon codes.
  • Sorting: s1.compareTo(s2) returns negative if s1 < s2, 0 if equal, and positive if s1 > s2. This is the foundation of Comparable in Java Collections.
  • Zero Object Allocation: Use s.contentEquals(sb) to check equality against a StringBuilder directly without calling sb.toString().
