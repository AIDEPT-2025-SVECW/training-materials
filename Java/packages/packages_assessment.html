Activity 1: Student Information Portal Architecture

Requirement: Create a clean 2-package architecture without using any collections:

  • In package edu.svecw.model: Create a Student class with private fields (id, name, cgpa), constructor, and public getters.
  • In package edu.svecw.service: Create a StudentReportService class that imports Student, determines whether the student receives "First Class with Distinction" (CGPA >= 8.5), and prints a formatted report card using String.format().
Expected Output:
======================================== SVECW STUDENT REPORT CARD ======================================== Student ID : 1024 Student Name : Ananya Sharma CGPA : 9.15 Performance : First Class with Distinction! ========================================
💡 Hints & Architecture Blueprint (Click to expand)
  • Place Student.java in a folder matching edu/svecw/model/.
  • Declare package edu.svecw.model; as line 1.
  • In StudentReportService.java, write import edu.svecw.model.Student;.
  • Verify that non-public members in Student cannot be directly accessed from the service class.
☕ Complete Java Solution: Multi-Package Portal
Student.java (edu.svecw.model) 
package edu.svecw.model;

public class Student {
    private final int id;
    private final String name;
    private final double cgpa;

    public Student(int id, String name, double cgpa) {
        this.id = id;
        this.name = name;
        this.cgpa = cgpa;
    }

    public int getId() { return id; }
    public String getName() { return name; }
    public double getCgpa() { return cgpa; }
}
StudentReportService.java (edu.svecw.service) 
package edu.svecw.service;

import edu.svecw.model.Student;

public class StudentReportService {
    public static void printReportCard(Student s) {
        String distinction = (s.getCgpa() >= 8.5) 
            ? "First Class with Distinction!" 
            : "First Class";

        System.out.println("========================================");
        System.out.println("       SVECW STUDENT REPORT CARD        ");
        System.out.println("========================================");
        System.out.println(String.format("Student ID   : %d", s.getId()));
        System.out.println(String.format("Student Name : %s", s.getName()));
        System.out.println(String.format("CGPA         : %.2f", s.getCgpa()));
        System.out.println(String.format("Performance  : %s", distinction));
        System.out.println("========================================");
    }

    public static void main(String[] args) {
        Student student = new Student(1024, "Ananya Sharma", 9.15);
        printReportCard(student);
    }
}

Activity 2: Zomato Food Order Lifecycle Engine

Requirement: Model order states using a rich Java `enum` without any external collections:

  • Create an enum OrderStatus with constants: PLACED, PREPARING, OUT_FOR_DELIVERY, DELIVERED.
  • Give each constant a statusCode (int), description (String), and estimatedMinutes (int).
  • Implement a helper method printOrderSummary() using a switch statement and iterate over all constants using values().
Expected Output:
--- ZOMATO ORDER PIPELINE --- [101] PLACED : Order received by restaurant (ETA: 5 mins) [102] PREPARING : Kitchen is preparing meal (ETA: 20 mins) [103] OUT_FOR_DELIVERY : Valet is on the way (ETA: 15 mins) [104] DELIVERED : Order delivered at doorstep (ETA: 0 mins) Current Order State: OUT_FOR_DELIVERY -> Track your valet on live map!
💡 Hints & Architecture Blueprint (Click to expand)
  • Constructor in an enum is always private.
  • Add private final fields: int code, String desc, int eta.
  • Use OrderStatus.values() to iterate through every constant.
☕ Complete Java Solution: Zomato Order Enum
ZomatoOrderEngine.java 
enum OrderStatus {
    PLACED(101, "Order received by restaurant", 5),
    PREPARING(102, "Kitchen is preparing meal", 20),
    OUT_FOR_DELIVERY(103, "Valet is on the way", 15),
    DELIVERED(104, "Order delivered at doorstep", 0);

    private final int code;
    private final String desc;
    private final int etaMinutes;

    OrderStatus(int code, String desc, int eta) {
        this.code = code;
        this.desc = desc;
        this.etaMinutes = eta;
    }

    public int getCode() { return code; }
    public String getDesc() { return desc; }
    public int getEtaMinutes() { return etaMinutes; }
}

public class ZomatoOrderEngine {
    public static void main(String[] args) {
        System.out.println("--- ZOMATO ORDER PIPELINE ---");
        for (OrderStatus status : OrderStatus.values()) {
            System.out.println(String.format("[%d] %-16s: %s (ETA: %d mins)",
                    status.getCode(), status.name(), status.getDesc(), status.getEtaMinutes()));
        }

        OrderStatus current = OrderStatus.OUT_FOR_DELIVERY;
        System.out.print("\nCurrent Order State: " + current + " -> ");
        switch (current) {
            case PLACED -> System.out.println("Waiting for kitchen approval.");
            case PREPARING -> System.out.println("Chef is cooking your dish.");
            case OUT_FOR_DELIVERY -> System.out.println("Track your valet on live map!");
            case DELIVERED -> System.out.println("Enjoy your meal!");
        }
    }
}
java.util.Random & Formatter

Activity 3: Banking OTP & Transaction Reference Generator

Requirement: Build a secure transaction helper class without any collections:

  • Use java.util.Random to generate a guaranteed 6-digit OTP (between 100000 and 999999).
  • Generate an alphanumeric transaction token in the format TXN-YYYY-XXXXXX (e.g., TXN-2026-834921) using String.format().
  • Demonstrate auto-boxing by storing the generated OTP into an Integer object and printing both.
Expected Output:
🔐 Generated 6-Digit Banking OTP: 492817 (Valid for 5 mins) 💳 Transaction Reference ID : TXN-2026-492817 ✨ Auto-boxed Integer Check : 492817 (Type: class java.lang.Integer)
💡 Hints & Architecture Blueprint (Click to expand)
  • To get a 6-digit number between 100000 and 999999: random.nextInt(900000) + 100000.
  • Format with 6-digit zero padding: String.format("%06d", otp).
  • Store into wrapper: Integer boxedOtp = otp; (Auto-boxing).
☕ Complete Java Solution: OTP & Token Generator
BankingSecurityUtil.java 
import java.util.Random;

public class BankingSecurityUtil {
    public static int generateOtp(Random random) {
        // Range: 100000 to 999999
        return random.nextInt(900000) + 100000;
    }

    public static String generateTxnId(int year, int otp) {
        return String.format("TXN-%d-%06d", year, otp);
    }

    public static void main(String[] args) {
        Random random = new Random();
        int rawOtp = generateOtp(random);

        // Auto-boxing: primitive int to Integer object
        Integer boxedOtp = rawOtp;
        String txnId = generateTxnId(2026, boxedOtp);

        System.out.println("🔐 Generated 6-Digit Banking OTP: " + boxedOtp + " (Valid for 5 mins)");
        System.out.println("💳 Transaction Reference ID    : " + txnId);
        System.out.println("✨ Auto-boxed Integer Check    : " + boxedOtp + " (Type: " + boxedOtp.getClass() + ")");
    }
}

TemporalAdjusters & DayOfWeek

Activity 5: Corporate Payroll Last Working Day Calculator

Requirement: In enterprise HR and banking systems, monthly employee salaries are credited on the last working day of the month:

  • Use TemporalAdjusters.lastDayOfMonth() to locate the last calendar day.
  • If the last day falls on a Saturday, salary is credited on Friday (-1 day).
  • If the last day falls on a Sunday, salary is credited on Friday (-2 days).
  • Test this for May 2026 (May 31 is a Sunday!) and print the adjusted salary credit date.
Expected Output:
--- TCS / INFOSYS MONTHLY PAYROLL DISBURSEMENT --- Requested Month : May 2026 Calendar Last Day : 2026-05-31 (SUNDAY) Weekend Conflict Rule : Sunday detected -> Shifting back by 2 days! Final Salary Credit Day: Friday, 29-May-2026
💡 Hints & Architecture Blueprint (Click to expand)
  • Get last day: LocalDate lastDay = LocalDate.of(year, month, 1).with(TemporalAdjusters.lastDayOfMonth());.
  • Check day: lastDay.getDayOfWeek() == DayOfWeek.SUNDAY.
  • Subtract days: lastDay.minusDays(2).
  • Format: DateTimeFormatter.ofPattern("EEEE, dd-MMM-yyyy").
☕ Complete Java Solution: Salary Day Adjuster
PayrollDisbursementEngine.java 
import java.time.LocalDate;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;
import java.time.format.DateTimeFormatter;

public class PayrollDisbursementEngine {
    public static void calculateSalaryDate(int year, int month) {
        LocalDate firstDay = LocalDate.of(year, month, 1);
        LocalDate lastDay = firstDay.with(TemporalAdjusters.lastDayOfMonth());

        LocalDate salaryDate = lastDay;
        String note = "Weekday -> No shift needed.";

        if (lastDay.getDayOfWeek() == DayOfWeek.SATURDAY) {
            salaryDate = lastDay.minusDays(1);
            note = "Saturday detected -> Shifting back by 1 day!";
        } else if (lastDay.getDayOfWeek() == DayOfWeek.SUNDAY) {
            salaryDate = lastDay.minusDays(2);
            note = "Sunday detected -> Shifting back by 2 days!";
        }

        DateTimeFormatter fmt = DateTimeFormatter.ofPattern("EEEE, dd-MMM-yyyy");

        System.out.println("--- TCS / INFOSYS MONTHLY PAYROLL DISBURSEMENT ---");
        System.out.println("Requested Month        : " + firstDay.getMonth() + " " + year);
        System.out.println("Calendar Last Day      : " + lastDay + " (" + lastDay.getDayOfWeek() + ")");
        System.out.println("Weekend Conflict Rule  : " + note);
        System.out.println("Final Salary Credit Day: " + salaryDate.format(fmt));
    }

    public static void main(String[] args) {
        // May 2026: May 31 is a Sunday!
        calculateSalaryDate(2026, 5);
    }
}
