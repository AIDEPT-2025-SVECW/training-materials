Random Class (java.util.Random)

Master pseudorandom number generation: 5 core methods, seed mechanics, stream generators, and security considerations for banking OTPs.

1. WHY: Why Does java.util.Random Exist?

While Math.random() returns a floating-point number between 0.0 and 1.0, real-world applications need random integers within a bounded range (e.g. 1 to 6 for Ludo dice), random booleans (for coin flips), random byte arrays, or streams of random numbers. java.util.Random provides a complete, reusable pseudorandom generator.

💡

2. WHAT: 5 Essential Methods of java.util.Random

1. public int nextInt(int bound)
Returns a uniformly distributed pseudorandom integer between 0 (inclusive) and bound (exclusive). Most frequently used method.
2. public double nextDouble()
Returns a pseudorandom double value between 0.0 and 1.0.
3. public boolean nextBoolean()
Returns a uniformly distributed boolean value (true or false with 50% probability).
4. public void nextBytes(byte[] bytes)
Fills the provided byte array with random bytes, commonly used in cryptographic salting or simulation payloads.
5. public IntStream ints(long streamSize, int origin, int bound)
Java 8+ Stream method returning an IntStream producing streamSize pseudorandom integers between origin and bound.
🚨
Crucial Enterprise Security Notice:
java.util.Random is NOT cryptographically secure! Its internal 48-bit seed is predictable. Never use java.util.Random for financial OTPs, passwords, or encryption keys! Always use java.security.SecureRandom for production banking and payment authentication.

3. HOW: Indian Mobile Banking 6-Digit OTP Generator

Demonstrating both java.util.Random (for games/simulation) and java.security.SecureRandom (for Indian UPI/Banking OTP authentication):

IndianOtpAndGameSimulator.java
package in.npci.security;

import java.util.Random;
import java.security.SecureRandom;

public class IndianOtpAndGameSimulator {

    // 1. Simulation / Gaming using java.util.Random
    public static int simulateLudoDiceRoll() {
        Random rng = new Random();
        // nextInt(6) returns 0..5, so + 1 gives 1..6
        return rng.nextInt(6) + 1;
    }

    // 2. Banking Security: Cryptographically Secure 6-Digit OTP Generator
    public static String generateBankingOtp() {
        SecureRandom secureRng = new SecureRandom();
        // Generate integer between 100000 and 999999
        int otpNumber = 100000 + secureRng.nextInt(900000);
        return String.valueOf(otpNumber);
    }

    public static void main(String[] args) {
        System.out.println("🎲 Ludo Board Game Dice Roll: " + simulateLudoDiceRoll());

        // Method 5: Stream of 3 random lucky draw winners
        Random lotteryRng = new Random();
        System.out.print("🎟️ IPL Festival Contest Winner IDs: ");
        lotteryRng.ints(3, 1000, 9999)
                  .forEach(id -> System.out.print("#" + id + " "));
        System.out.println();

        String upiOtp = generateBankingOtp();
        System.out.println("\n📲 [PhonePe / NPCI Alert] Your one-time OTP is: " + upiOtp);
        System.out.println("Valid for 5 minutes. Do not share with anyone.");
    }
}

📌 Key Takeaways

  • Why: Generates pseudorandom values of any primitive type and random stream pipelines.
  • What: 5 primary methods: nextInt(bound), nextDouble(), nextBoolean(), nextBytes(), ints().
  • How: Use Random for non-security simulations and switch to SecureRandom for passwords and OTP generation.
