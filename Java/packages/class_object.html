Class Object (java.lang.Object)

The universal ancestor of all classes in Java. Master its 5 essential methods, the equals-hashCode contract, and real-world domain entity modeling.

👑 Universal Superclass ⚖️ equals & hashCode 📋 toString & getClass
❓

1. WHY: Why Does Java Have a Universal Root Class?

In Java, every class automatically extends java.lang.Object if it doesn't explicitly extend another class. This universal root ensures:

  • Universal Polymorphism: Any instance of any class can be referenced by Object obj, enabling generic data structures and universal serialization.
  • Guaranteed Baseline Behavior: Every object is guaranteed to possess methods for string conversion, equality testing, hash code calculation, and thread synchronization.
💡

2. WHAT: The 5 Essential Methods of Class Object

While Object contains 11 methods in total, these 5 are fundamental to daily Java programming:

1. public String toString()
Returns a textual representation of the object. By default, it returns ClassName@HexHashCode. Should always be overridden to display human-readable state.
2. public boolean equals(Object obj)
Checks whether two objects are logically equal. Default implementation checks reference equality (==). Overridden for value-based equivalence.
3. public int hashCode()
Returns an integer hash value used by hash-based collections (HashMap, HashSet). Must obey the contract with equals()!
4. public final Class<?> getClass()
Returns the runtime Class object representing the entity's exact runtime type. Crucial for reflection and dynamic type checks. Cannot be overridden.
5. protected Object clone() throws CloneNotSupportedException
Creates and returns a field-by-field shallow copy of the object. Requires the class to implement the marker interface Cloneable.
⚖️
The Golden equals-hashCode Contract:
If two objects are equal according to equals(Object), they MUST produce the exact same integer from hashCode(). If you override equals, you MUST override hashCode! Failing to do so breaks HashMap lookups.

3. HOW: Indian Aadhaar Citizen Model with equals() & hashCode()

Here is how to properly implement toString(), equals(), and hashCode() in an Indian Aadhaar identification system:

AadhaarCard.java (Overriding Object Methods)
package in.gov.uidai.model;

import java.util.Objects;

public class AadhaarCard {
    private final String aadhaarNumber; // 12-digit unique national ID
    private final String citizenName;
    private final String state;

    public AadhaarCard(String aadhaarNumber, String citizenName, String state) {
        this.aadhaarNumber = aadhaarNumber;
        this.citizenName = citizenName;
        this.state = state;
    }

    // Method 1: Meaningful string output
    @Override
    public String toString() {
        return String.format("AadhaarCard[UID=XXXX-XXXX-%s, Name=%s, State=%s]",
                aadhaarNumber.substring(8), citizenName, state);
    }

    // Method 2: Logical equality based on unique Aadhaar number
    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;                          // Same reference
        if (obj == null || getClass() != obj.getClass()) return false; // Type check using getClass()
        AadhaarCard other = (AadhaarCard) obj;
        return Objects.equals(aadhaarNumber, other.aadhaarNumber);
    }

    // Method 3: Hash code contract
    @Override
    public int hashCode() {
        return Objects.hash(aadhaarNumber);
    }

    public static void main(String[] args) {
        AadhaarCard c1 = new AadhaarCard("987654321012", "Ananya Verma", "Karnataka");
        AadhaarCard c2 = new AadhaarCard("987654321012", "Ananya V.", "Karnataka");

        System.out.println("Card 1: " + c1);
        System.out.println("Are both cards logically equal? " + c1.equals(c2));
        System.out.println("Do hashcodes match? " + (c1.hashCode() == c2.hashCode()));
        System.out.println("Runtime Class: " + c1.getClass().getName());
    }
}

📌 Key Takeaways

  • Why: The universal ancestor enabling uniform polymorphism and default baseline capabilities.
  • What: 5 primary methods: toString(), equals(), hashCode(), getClass(), clone().
  • How: Override equals() and hashCode() together using key business identifiers (like Aadhaar or PAN number).
