1. WHY: The Role of java.util in Enterprise Software

While java.lang provides language fundamentals (objects, strings, threads), practical applications require data structures (lists, key-value maps, queues), algorithms (sorting, searching), input parsing (Scanner), and value safety (Optional). The java.util package serves as the standard utility library for every Java backend.

3. HOW: Indian Railway Station Master Directory

A practical Indian Railways search service utilizing Map, List, Optional, and Objects:

IndianRailwayStationDirectory.java
package in.gov.irctc.directory;

import java.util.Map;
import java.util.HashMap;
import java.util.List;
import java.util.Arrays;
import java.util.Optional;
import java.util.Objects;

public class IndianRailwayStationDirectory {
    private final Map<String, String> stationCodes = new HashMap<>();

    public IndianRailwayStationDirectory() {
        stationCodes.put("NDLS", "New Delhi Railway Station");
        stationCodes.put("SBC", "KSR Bengaluru City Junction");
        stationCodes.put("MAS", "MGR Chennai Central");
        stationCodes.put("SC", "Secunderabad Junction");
        stationCodes.put("HWH", "Howrah Junction (Kolkata)");
    }

    // Returns an Optional to protect caller from NullPointerException
    public Optional<String> findStationName(String code) {
        Objects.requireNonNull(code, "Station code must not be null");
        return Optional.ofNullable(stationCodes.get(code.toUpperCase()));
    }

    public static void main(String[] args) {
        IndianRailwayStationDirectory dir = new IndianRailwayStationDirectory();

        List<String> searchCodes = Arrays.asList("SBC", "NDLS", "PNBE");

        for (String code : searchCodes) {
            String name = dir.findStationName(code)
                             .orElse("Unknown Station Code in IRCTC database");
            System.out.println(String.format("Code: %-6s -> %s", code, name));
        }
    }
}
