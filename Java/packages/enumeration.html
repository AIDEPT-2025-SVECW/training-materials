Enumerations in Java (java.lang.Enum)

From beginner-friendly basics to advanced types: master enum definition, simple usage with colors, type safety, the 5 key methods, and custom attributes.

1. DEFINITION: What is an Enum?

In Java, an enum (short for enumeration) is to create a custom type that has a fixed set of constant values.

  • We use the enum keyword to declare enums.
  • For example,
    Color.java
    enum Color { RED, GREEN, BLUE }
  • Here, we have created an enum named Color. It contains fixed values RED, GREEN, BLUE.
  • These values inside the braces are called enum constants (values).
📌 Note: The enum constants are usually represented in uppercase.

🌱 Meaning of "Enumeration"

The English word enumerate means "to name or list one by one". In Java, an enum represents an explicit, fixed list of named constant values.

🔒 A Distinct Custom Type

Color is not just a collection of strings or integers. It creates a distinct reference type in Java. A variable of type Color can hold only defined Color values or null.

🎨

2. FRESHER QUICK START: Simple Usage with Colors

Before diving into advanced enum features, let's look at how a beginner works with enums in everyday Java code:

1 Declare & Assign

Access an enum constant using EnumName.CONSTANT:

Color myColor = Color.RED;

2 Safe Comparison with `==`

Because enum constants are singletons, compare them directly using ==:

if (myColor == Color.RED) { ... }

3 Clean `switch-case` Statements

Inside switch case labels, write the constant name directly without the prefix:

case RED: System.out.println("Stop");

4 Loop with `.values()`

Iterate over every declared constant easily with an enhanced for-loop:

for (Color c : Color.values()) { ... }

💻 Complete Beginner Demo: SimpleColorDemo.java

SimpleColorDemo.java
// Step 1: Define the Color enum
enum Color {
    RED, GREEN, BLUE
}

public class SimpleColorDemo {
    public static void main(String[] args) {
        // 1. Declaring and initializing an enum variable
        Color selectedColor = Color.RED;
        System.out.println("Selected color is: " + selectedColor);

        // 2. Checking with if-else using ==
        if (selectedColor == Color.RED) {
            System.out.println("Traffic light says: STOP!");
        }

        // 3. Using Color in a switch-case statement
        // Note: inside case labels, write RED, GREEN, BLUE (not Color.RED)
        System.out.println("\nTraffic advice by switch:");
        switch (selectedColor) {
            case RED:
                System.out.println("⛔ STOP! Wait for the light to turn green.");
                break;
            case GREEN:
                System.out.println("🟢 GO! The roadway is clear.");
                break;
            case BLUE:
                System.out.println("🔵 INFO: Service lane only.");
                break;
        }

        // 4. Iterating over all available values using Color.values()
        System.out.println("\nAll available Color options in the enum:");
        for (Color c : Color.values()) {
            System.out.println("-> " + c);
        }
    }
}
🖥️ Console Output:
Selected color is: RED Traffic light says: STOP! Traffic advice by switch: ⛔ STOP! Wait for the light to turn green. All available Color options in the enum: -> RED -> GREEN -> BLUE

💡 Fresher Quick Tips

  • No `new` Keyword: You never instantiate an enum with new Color(). Enum constants are fixed singletons instantiated once by the JVM.
  • Strict Type Safety: You cannot assign arbitrary values like Color c = "RED"; or Color c = 1;. The compiler rejects invalid assignments immediately!
  • Where to declare: You can declare an enum in its own file (Color.java), outside a class in the same file, or as a static member inside another class.

3. WHY: Why Enums Beat Old-Fashioned `int` Constants

Before Java 5, developers declared constants using integer flags: public static final int SLEEPER = 1;. This had major design flaws:

❌ No Type Safety

If a booking method takes int coachType, you could accidentally pass PaymentStatus.FAILED (value 1) instead of Coach.SLEEPER (value 1). The compiler cannot catch this blunder!

✅ Enums: 100% Type Safe

Enums create a distinct custom reference type. If a method expects IrctcCoach, only valid constants from that enum can be passed at compile time.

💡

4. WHAT: The 5 Essential Methods of Enum

Every enum implicitly extends java.lang.Enum<E> and automatically receives these 5 key methods:

1. public static E[] values()
Compiler-generated static method that returns an array containing all declared constants in declaration order. Perfect for UI dropdowns or for-each iterations.
2. public static E valueOf(String name)
Parses a string and returns the matching enum constant. Throws IllegalArgumentException if no matching constant exists.
3. public final String name()
Returns the exact declared identifier of this enum constant (e.g., "AC_FIRST_CLASS"). Distinct from toString() which can be overridden.
4. public final int ordinal()
Returns the zero-based numeric index of the constant according to declaration order (0 for first, 1 for second).
5. public final int compareTo(E other)
Compares this enum with the specified object based on their ordinal sequence order.

5. ADVANCED: IRCTC Train Coach Type with Custom Properties

Now that you've mastered the basics, let's explore advanced enums! Enums in Java are full-blown classes! They can have constructors, private fields, and methods:

IrctcCoach.java (Rich Enum with Custom Attributes)
package in.gov.irctc.model;

public enum IrctcCoach {
    // 1. Constants with custom constructor parameters
    AC_FIRST_CLASS("1A", 3.5, true),
    AC_TWO_TIER("2A", 2.2, true),
    AC_THREE_TIER("3A", 1.6, true),
    SLEEPER("SL", 1.0, false),
    GENERAL("GN", 0.6, false);

    private final String code;
    private final double fareMultiplier;
    private final boolean airConditioned;

    // Enum constructor is always private
    IrctcCoach(String code, double multiplier, boolean ac) {
        this.code = code;
        this.fareMultiplier = multiplier;
        this.airConditioned = ac;
    }

    public double calculateFare(double baseFare) {
        return baseFare * fareMultiplier;
    }

    public static void main(String[] args) {
        double standardBaseFare = 450.00; // e.g., Hyderabad to Visakhapatnam

        System.out.println("🚂 IRCTC Coach Options & Fares:");
        // Method 1: Iterating over values()
        for (IrctcCoach coach : IrctcCoach.values()) {
            System.out.println(String.format("%-15s [%s] AC: %-5b Ordinal: %d Fare: ₹ %.2f",
                    coach.name(), coach.code, coach.airConditioned, coach.ordinal(), coach.calculateFare(standardBaseFare)));
        }

        // Method 2: valueOf() parsing
        IrctcCoach selected = IrctcCoach.valueOf("AC_THREE_TIER");
        System.out.println("\nPassenger selected: " + selected.name() + " -> Fare: ₹ " + selected.calculateFare(standardBaseFare));
    }
}

📌 Key Takeaways

  • Definition: In Java, an enum is used to create a custom type with a fixed set of constant values (e.g., RED, GREEN, BLUE) using the enum keyword.
  • Fresher Quick Start: Access constants via Color.RED, compare safely with ==, use in switch, and loop with Color.values().
  • Why: Replaces unsafe integer constants with strict compile-time types.
  • What: Inherits from java.lang.Enum with 5 key methods: values(), valueOf(), name(), ordinal(), compareTo().
  • Advanced: Can encapsulate fields, constructors, and business logic methods (like the IrctcCoach model).
