Formatting for Date/Time in Java (DateTimeFormatter)

Master thread-safe date formatting, parsing standard Indian date representations (dd/MM/yyyy), custom pattern patterns, and localized formatting.

🧵 100% Thread-Safe 🇮🇳 dd/MM/yyyy Indian Format ✈️ Air India Boarding Pass
❓

1. WHY: Why Did SimpleDateFormat Have to Be Replaced?

Prior to Java 8, Java developers used java.text.SimpleDateFormat. It had a severe design flaw: it was mutable and NOT thread-safe. When shared across multiple request threads in web services, it frequently produced corrupted dates or threw NumberFormatException.

java.time.format.DateTimeFormatter is completely immutable and thread-safe. A single instance can be safely shared across thousands of concurrent threads as a static constant.

💡

2. WHAT: 5 Essential Methods of DateTimeFormatter

1. public static DateTimeFormatter ofPattern(String pattern)
Creates a formatter using the specified custom pattern (e.g., "dd-MM-yyyy hh:mm a").
2. public String format(TemporalAccessor temporal)
Formats a modern date-time object (LocalDate, ZonedDateTime) into a formatted string representation.
3. public <T> T parse(CharSequence text, TemporalQuery<T> query)
Fully parses the specified text into a temporal date object (also called conveniently via LocalDate.parse(text, formatter)).
4. public DateTimeFormatter withZone(ZoneId zone)
Returns a copy of this formatter configured with a specific override timezone (e.g., ZoneId.of("Asia/Kolkata")).
5. public DateTimeFormatter withLocale(Locale locale)
Returns a copy of this formatter with the specified locale for language-specific month names and day names.

3. HOW: Air India Flight Boarding Pass & Passport Expiry Parser

Demonstrating both parsing customer input in Indian format (dd/MM/yyyy) and printing international boarding passes:

AirIndiaFlightFormatter.java
package in.airindia.flight;

import java.time.LocalDate;
import java.time.ZonedDateTime;
import java.time.ZoneId;
import java.time.format.DateTimeFormatter;
import java.util.Locale;

public class AirIndiaFlightFormatter {
    // Formatter instances are thread-safe and can be static constants!
    private static final DateTimeFormatter INDIAN_DATE_FORMAT = 
            DateTimeFormatter.ofPattern("dd/MM/yyyy");

    private static final DateTimeFormatter BOARDING_PASS_FORMAT = 
            DateTimeFormatter.ofPattern("EEE, dd MMM yyyy - hh:mm a (z)", Locale.of("en", "IN"));

    public static void main(String[] args) {
        // 1. Parsing Indian Passport Expiry Date String
        String passportExpiryStr = "28/05/2031";
        LocalDate expiryDate = LocalDate.parse(passportExpiryStr, INDIAN_DATE_FORMAT);
        System.out.println("🛂 Parsed Passport Expiry Date: " + expiryDate);

        // 2. Generating Boarding Pass Departure Timestamp in IST
        ZonedDateTime departureTime = ZonedDateTime.now(ZoneId.of("Asia/Kolkata"));
        String formattedBoardingTime = departureTime.format(BOARDING_PASS_FORMAT);

        System.out.println("\n✈️ --- AIR INDIA BOARDING PASS ---");
        System.out.println("Flight: AI-101 (DEL -> JFK)");
        System.out.println("Departure: " + formattedBoardingTime);
        System.out.println("Gate Closes 25 mins prior to departure");
    }
}

📌 Key Takeaways

  • Why: Replaced non-thread-safe SimpleDateFormat with immutable, thread-safe formatters.
  • What: 5 key methods: ofPattern(), format(), parse(), withZone(), withLocale().
  • How: Use standard patterns like "dd/MM/yyyy" for Indian applications and declare formatters as static final.
