💡 Understanding Array Assignment & Method Passing

1. Array Assignment (`int[] b = a;`)

Executing int[] b = a; does NOT copy the elements! It copies the reference address. Both a and b now point to the exact same array in Heap memory. Modifying b[0] changes a[0]!

2. Pass-by-Value of Reference

Java is strictly Pass-by-Value. When passing an array to a method, Java passes a copy of the reference address:
• Modifying elements inside method ➔ Affects caller!
• Reassigning method variable (arr = new int[5]) ➔ Does NOT affect caller!

1. Primitive Array References in Methods

ArrayPassingDemo.java
Java 17+ 
public class ArrayPassingDemo {
    public static void main(String[] args) {
        int[] original = {10, 20, 30};

        System.out.println("Original before method: " + original[0]); // 10

        // 1. Method that modifies array elements
        modifyArrayElements(original);
        System.out.println("Original after modifyArrayElements: " + original[0]); // 99 (MUTATED!)

        // 2. Method that reassigns local reference
        reassignArrayReference(original);
        System.out.println("Original after reassignArrayReference: " + original[0]); // Still 99!
    }

    public static void modifyArrayElements(int[] arr) {
        arr[0] = 99; // Modifies Heap object referenced by original!
    }

    public static void reassignArrayReference(int[] arr) {
        arr = new int[]{500, 600, 700}; // Points arr to NEW object; original untouched!
    }
}
🖥️ Output:
Original before method: 10
Original after modifyArrayElements: 99
Original after reassignArrayReference: 99

2. Passing & Returning Object Arrays in Methods

When an array of custom class objects is passed to a method, mutating object attributes inside the method updates the actual shared Heap objects. Methods can also process, filter, and return new object arrays.

ObjectArrayPassingDemo.java
Java 17+ 
// Custom Employee Class
class Employee {
    String name;
    double salary;

    Employee(String name, double salary) {
        this.name = name;
        this.salary = salary;
    }

    void display() {
        System.out.printf("Employee: %-8s | Salary: ₹%.2f%n", name, salary);
    }
}

public class ObjectArrayPassingDemo {
    public static void main(String[] args) {
        Employee[] staff = {
            new Employee("Anil", 50000),
            new Employee("Sunita", 65000),
            new Employee("Rajesh", 48000)
        };

        System.out.println("=== Staff Before Salary Raise ===");
        for (Employee e : staff) e.display();

        // 1. Pass object array to method (Mutates internal objects on Heap)
        giveSalaryRaise(staff, 10.0);

        System.out.println("\n=== Staff After 10% Raise ===");
        for (Employee e : staff) e.display();

        // 2. Method returning a newly created & filtered Object Array
        Employee[] highEarners = filterHighEarners(staff, 60000);

        System.out.println("\n=== High Earners (> ₹60,000) ===");
        for (Employee e : highEarners) e.display();
    }

    // Mutates object properties inside the passed array
    public static void giveSalaryRaise(Employee[] employees, double percentage) {
        for (Employee e : employees) {
            if (e != null) {
                e.salary += e.salary * (percentage / 100.0);
            }
        }
    }

    // Filters objects and returns a new Object Array
    public static Employee[] filterHighEarners(Employee[] employees, double minSalary) {
        int count = 0;
        for (Employee e : employees) {
            if (e != null && e.salary >= minSalary) count++;
        }

        Employee[] result = new Employee[count];
        int idx = 0;
        for (Employee e : employees) {
            if (e != null && e.salary >= minSalary) {
                result[idx++] = e;
            }
        }
        return result;
    }
}
🖥️ Output:
=== Staff Before Salary Raise ===
Employee: Anil | Salary: ₹50000.00
Employee: Sunita | Salary: ₹65000.00
Employee: Rajesh | Salary: ₹48000.00

=== Staff After 10% Raise ===
Employee: Anil | Salary: ₹55000.00
Employee: Sunita | Salary: ₹71500.00
Employee: Rajesh | Salary: ₹52800.00

=== High Earners (> ₹60,000) ===
Employee: Sunita | Salary: ₹71500.00
