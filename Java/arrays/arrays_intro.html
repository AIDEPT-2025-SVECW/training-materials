Arrays Introduction & Purpose

Master why arrays are the foundational data structure in computer science for organizing related fixed-size data efficiently in memory.

📦 Contiguous Memory ⚡ O(1) Instant Access 🎯 Fixed Length 🧬 Homogeneous Types

💡 What is an Array and Why Do We Need It?

❌ Problem: Without Arrays

Imagine storing exam scores for 5 students without arrays. You must declare 5 separate variable names:

int score1 = 85;
int score2 = 92;
int score3 = 78;
int score4 = 90;
int score5 = 88;

Drawbacks: Unscalable! Storing 1,000 students requires 1,000 variable names. You cannot easily loop through them!

✅ Solution: With Arrays

An array stores all 5 scores under a single container name with indices 0 through 4:

int[] scores = {85, 92, 78, 90, 88};

Advantages: Single variable name, easy loop traversal, fixed memory block, O(1) direct access time.

💻 Complete Java Program Example

ArraysIntroDemo.java
Java 17+ 
public class ArraysIntroDemo {
    public static void main(String[] args) {
        // 1. Storing data in an array
        int[] studentScores = {85, 92, 78, 90, 88};

        // 2. Displaying total elements using .length property
        System.out.println("Total Students: " + studentScores.length);

        // 3. Accessing elements by 0-based index
        System.out.println("First Student Score [0]: " + studentScores[0]);
        System.out.println("Third Student Score [2]: " + studentScores[2]);

        // 4. Calculating total score using loop
        int total = 0;
        for (int score : studentScores) {
            total += score;
        }

        double average = (double) total / studentScores.length;
        System.out.println("Class Average: " + average);
    }
}
🖥️ Program Output:
Total Students: 5
First Student Score [0]: 85
Third Student Score [2]: 78
Class Average: 86.6
