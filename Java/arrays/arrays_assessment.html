🛒 Scenario 1: Supermarket Checkout & Discount Scanner
Simple Complexity
You are building a software module for a retail store POS checkout counter. A customer purchases multiple items whose price tags are scanned into an array double[] prices. Write a program to:
  1. Calculate the total bill before discount.
  2. Find the price of the most expensive item and the cheapest item.
  3. Apply a 10% discount on the total bill if the total before discount exceeds $100.00.
  4. Display a warning alert if any item price is negative (invalid scanned price).
Sample Input: double[] prices = {15.50, 42.00, 8.75, 55.20, 12.00};
Expected Output:
Total Bill (Gross): $133.45
Most Expensive Item: $55.20
Cheapest Item: $8.75
Eligible for 10% Discount: YES
Final Payable Amount: $120.11
💡 Hints & Algorithm Blueprint (Click to expand before looking at code)
  • Validation Check: Iterate through the array first or inside the loop checking if prices[i] < 0.
  • Min/Max Initialization: Initialize max = prices[0] and min = prices[0].
  • Accumulation: Use an accumulator variable double total = 0 to sum up items during loop traversal.
  • Conditional Discount: Check if (total > 100) finalBill = total * 0.90;.
☕ Complete Java Code Reference Solution
SupermarketCheckout.java 
public class SupermarketCheckout {
    public static void main(String[] args) {
        double[] prices = {15.50, 42.00, 8.75, 55.20, 12.00};

        double total = 0.0;
        double maxPrice = prices[0];
        double minPrice = prices[0];
        boolean hasInvalidPrice = false;

        for (double price : prices) {
            if (price < 0) {
                System.out.println("⚠️ Invalid negative price detected: $" + price);
                hasInvalidPrice = true;
                continue;
            }
            total += price;
            if (price > maxPrice) maxPrice = price;
            if (price < minPrice) minPrice = price;
        }

        if (!hasInvalidPrice) {
            double finalAmount = (total > 100.00) ? (total * 0.90) : total;
            
            System.out.printf("Total Bill (Gross): $%.2f%n", total);
            System.out.printf("Most Expensive Item: $%.2f%n", maxPrice);
            System.out.printf("Cheapest Item: $%.2f%n", minPrice);
            System.out.println("Eligible for 10%% Discount: " + (total > 100.00 ? "YES" : "NO"));
            System.out.printf("Final Payable Amount: $%.2f%n", finalAmount);
        }
    }
}
🌡️ Scenario 2: Weather Station 7-Day Temperature Trend
Simple Complexity
A meteorological station logs the average daily temperature (in °C) over a 7-day period into double[] temps. Write a program to:
  1. Calculate the week's average temperature.
  2. List all days (Day 1 to Day 7) that had temperatures strictly above average.
  3. Find the maximum temperature change between any two consecutive days (e.g., |temps[i] - temps[i-1]|).
Sample Input: double[] temps = {28.5, 31.0, 26.5, 29.0, 34.5, 33.0, 27.5};
Expected Output:
Weekly Average Temperature: 30.00°C
Days Above Average: Day 2 (31.0°C), Day 5 (34.5°C), Day 6 (33.0°C)
Max 24-hr Temperature Jump: 5.50°C (Between Day 4 and Day 5)
💡 Hints & Algorithm Blueprint
  • Pass 1: Calculate average by finding sum of all elements and dividing by temps.length.
  • Pass 2: Loop from i = 0 to temps.length - 1 to print days where temps[i] > average.
  • Consecutive Delta: Loop from i = 1 to temps.length - 1, compute Math.abs(temps[i] - temps[i-1]), and update max difference tracker.
☕ Complete Java Code Reference Solution
WeatherMonitor.java 
public class WeatherMonitor {
    public static void main(String[] args) {
        double[] temps = {28.5, 31.0, 26.5, 29.0, 34.5, 33.0, 27.5};

        double sum = 0;
        for (double t : temps) sum += t;
        double avg = sum / temps.length;

        System.out.printf("Weekly Average Temperature: %.2f°C%n", avg);
        System.out.print("Days Above Average: ");
        for (int i = 0; i < temps.length; i++) {
            if (temps[i] > avg) {
                System.out.printf("Day %d (%.1f°C) ", (i + 1), temps[i]);
            }
        }
        System.out.println();

        double maxJump = 0;
        int jumpDay = 1;
        for (int i = 1; i < temps.length; i++) {
            double diff = Math.abs(temps[i] - temps[i - 1]);
            if (diff > maxJump) {
                maxJump = diff;
                jumpDay = i;
            }
        }
        System.out.printf("Max 24-hr Temperature Jump: %.2f°C (Between Day %d and Day %d)%n", maxJump, jumpDay, jumpDay + 1);
    }
}
📊 Scenario 3: Student Examination Pass/Fail Classifier
Simple Complexity
A university exam control office has an array of student marks int[] marks out of 100. Write a Java program to:
  1. Count total students who Passed (mark ≥ 50) vs Failed (mark < 50).
  2. Categorize students into performance buckets:
    • Distinction: Mark ≥ 85
    • First Class: Mark 70 to 84
    • Pass: Mark 50 to 69
    • Fail: Mark < 50
  3. Find the highest score in the batch.
Sample Input: int[] marks = {45, 88, 72, 90, 38, 65, 81};
Expected Output:
Total Passed: 5 | Total Failed: 2
Distinction Count (≥85): 2 (Marks: 88, 90)
First Class Count (70-84): 2 (Marks: 72, 81)
Pass Count (50-69): 1 (Mark: 65)
Fail Count (<50): 2 (Marks: 45, 38)
Top Score in Class: 90
💡 Hints & Algorithm Blueprint
  • Maintain 4 counter variables: distinctionCount, firstClassCount, passCount, failCount.
  • Loop through the array using a standard for loop or enhanced for-each loop.
  • Use if-else if-else blocks to evaluate each score.
☕ Complete Java Code Reference Solution
StudentGradeAnalyzer.java 
public class StudentGradeAnalyzer {
    public static void main(String[] args) {
        int[] marks = {45, 88, 72, 90, 38, 65, 81};

        int distinction = 0, firstClass = 0, pass = 0, fail = 0;
        int topScore = marks[0];

        for (int m : marks) {
            if (m > topScore) topScore = m;

            if (m >= 85) {
                distinction++;
            } else if (m >= 70) {
                firstClass++;
            } else if (m >= 50) {
                pass++;
            } else {
                fail++;
            }
        }

        System.out.println("Total Passed: " + (distinction + firstClass + pass) + " | Total Failed: " + fail);
        System.out.println("Distinction (>=85): " + distinction);
        System.out.println("First Class (70-84): " + firstClass);
        System.out.println("Pass (50-69): " + pass);
        System.out.println("Fail (<50): " + fail);
        System.out.println("Top Score in Class: " + topScore);
    }
}

📦 Scenario 4: Warehouse SKU Barcode Duplicate Cleaning
Medium Complexity
An automated barcode scanner at a distribution center scans product SKUs into an array int[] skus. Due to scanner glitches, duplicate entries exist. Constraint: Do NOT use Java Collections (like ArrayList or HashSet). Write a program using pure array logic to:
  1. Count the frequency of occurrence for each SKU.
  2. Extract and construct a new array int[] uniqueSkus containing only distinct SKUs in their original order of appearance.
Sample Input: int[] skus = {101, 204, 101, 305, 204, 101, 408};
Expected Output:
Unique SKUs Array: [101, 204, 305, 408]
SKU Frequency Breakdown:
- SKU 101: 3 times
- SKU 204: 2 times
- SKU 305: 1 time
- SKU 408: 1 time
💡 Hints & Algorithm Blueprint
  • Step 1 (Count Unique): Loop through the array. For each element, check if it appeared earlier in the array (`j < i`). If not, increment `uniqueCount`.
  • Step 2 (Allocate Array): Create `int[] uniqueSkus = new int[uniqueCount]`.
  • Step 3 (Fill & Count Frequencies): Populate `uniqueSkus` and count how many times each item appears in the original array using nested loops.
☕ Complete Java Code Reference Solution
WarehouseSKUCleaner.java 
public class WarehouseSKUCleaner {
    public static void main(String[] args) {
        int[] skus = {101, 204, 101, 305, 204, 101, 408};

        // Step 1: Count distinct elements
        int uniqueCount = 0;
        for (int i = 0; i < skus.length; i++) {
            boolean isDuplicate = false;
            for (int j = 0; j < i; j++) {
                if (skus[i] == skus[j]) {
                    isDuplicate = true;
                    break;
                }
            }
            if (!isDuplicate) uniqueCount++;
        }

        // Step 2: Populate unique array
        int[] uniqueSkus = new int[uniqueCount];
        int index = 0;
        for (int i = 0; i < skus.length; i++) {
            boolean isDuplicate = false;
            for (int j = 0; j < i; j++) {
                if (skus[i] == skus[j]) {
                    isDuplicate = true;
                    break;
                }
            }
            if (!isDuplicate) {
                uniqueSkus[index++] = skus[i];
            }
        }

        // Step 3: Frequency breakdown
        System.out.print("Unique SKUs Array: [");
        for (int i = 0; i < uniqueSkus.length; i++) {
            System.out.print(uniqueSkus[i] + (i < uniqueSkus.length - 1 ? ", " : ""));
        }
        System.out.println("]");

        System.out.println("SKU Frequency Breakdown:");
        for (int u : uniqueSkus) {
            int freq = 0;
            for (int s : skus) {
                if (s == u) freq++;
            }
            System.out.println("- SKU " + u + ": " + freq + " time(s)");
        }
    }
}
💳 Scenario 5: Financial Log Timezone Shift (Left Array Rotation)
Medium Complexity
A core banking system records hourly transaction sequence IDs into int[] logs. When adjusting log indexes for a server time-zone shift, the system needs to left-rotate the array by K positions.
E.g., rotating [10, 20, 30, 40, 50] left by K = 2 results in [30, 40, 50, 10, 20]. Write a program to perform left rotation for any given K. Handle edge cases where K > logs.length using modulo math.
Sample Input: int[] logs = {1001, 1002, 1003, 1004, 1005, 1006}; and int K = 2;
Expected Output:
Original Logs: [1001, 1002, 1003, 1004, 1005, 1006]
Shifted Logs (K=2): [1003, 1004, 1005, 1006, 1001, 1002]
💡 Hints & Algorithm Blueprint
  • Effective Shift: Compute K = K % N (where N is array length).
  • Approach 1 (Auxiliary Array): Copy elements from index K to N-1 into new array index 0 onwards, then copy elements 0 to K-1 to the remaining slots.
  • Approach 2 (In-Place Reversal Algorithm):
    1. Reverse first K elements [0 ... K-1].
    2. Reverse remaining elements [K ... N-1].
    3. Reverse entire array [0 ... N-1].
☕ Complete Java Code Reference Solution
ArrayRotation.java 
public class ArrayRotation {
    public static void main(String[] args) {
        int[] logs = {1001, 1002, 1003, 1004, 1005, 1006};
        int k = 2;
        int n = logs.length;

        k = k % n; // Handle k > n

        // Auxiliary Array Approach (Simple & intuitive for students)
        int[] rotated = new int[n];

        for (int i = 0; i < n; i++) {
            int newIndex = (i + n - k) % n;
            rotated[newIndex] = logs[i];
        }

        System.out.print("Rotated Logs: [");
        for (int i = 0; i < n; i++) {
            System.out.print(rotated[i] + (i < n - 1 ? ", " : ""));
        }
        System.out.println("]");
    }
}
🏢 Scenario 6: 2D Classroom Attendance Heatmap & Desk Grid
Medium Complexity
A digital attendance system stores desk seating for a hall in a 2D char[][] grid where:
  • 'P' = Present Student
  • 'A' = Absent Student
  • 'E' = Empty Unassigned Desk
Write a program to:
  1. Compute total attendance percentage (Present / Total Assigned Desks (P+A)).
  2. Find the row (desk line) with the maximum number of present students.
  3. Print a formatted classroom seating grid to the console.
Sample Input Grid:
Row 0: ['P', 'P', 'A', 'P']
Row 1: ['P', 'A', 'P', 'P']
Row 2: ['E', 'P', 'P', 'P']

Expected Output:
Classroom Attendance Rate: 81.82% (9 Present out of 11 Assigned Desks)
Row with Highest Attendance: Row 0 & Row 1 (3 Present)
💡 Hints & Algorithm Blueprint
  • Use nested loops: outer loop for (int r = 0; r < grid.length; r++), inner loop for (int c = 0; c < grid[r].length; c++).
  • Count total 'P', 'A', and 'E' characters across the entire grid.
  • Track row-wise present student count to find max row.
☕ Complete Java Code Reference Solution
ClassroomGrid.java 
public class ClassroomGrid {
    public static void main(String[] args) {
        char[][] grid = {
            {'P', 'P', 'A', 'P'},
            {'P', 'A', 'P', 'P'},
            {'E', 'P', 'P', 'P'}
        };

        int presentCount = 0;
        int absentCount = 0;
        int maxPresentInRow = -1;
        int bestRow = 0;

        System.out.println("--- Classroom Seating Layout ---");
        for (int r = 0; r < grid.length; r++) {
            int rowPresent = 0;
            System.out.print("Row " + r + ": ");
            for (int c = 0; c < grid[r].length; c++) {
                char ch = grid[r][c];
                System.out.print(ch + " ");
                if (ch == 'P') { presentCount++; rowPresent++; }
                else if (ch == 'A') absentCount++;
            }
            System.out.println("(Present: " + rowPresent + ")");

            if (rowPresent > maxPresentInRow) {
                maxPresentInRow = rowPresent;
                bestRow = r;
            }
        }

        int totalAssigned = presentCount + absentCount;
        double rate = (totalAssigned == 0) ? 0.0 : ((double) presentCount / totalAssigned) * 100;

        System.out.printf("%nClassroom Attendance Rate: %.2f%%%n", rate);
        System.out.println("Row with Highest Attendance: Row " + bestRow + " (" + maxPresentInRow + " students)");
    }
}
🖼️ Scenario 7: Digital Image Matrix Horizontal Mirror Flip
Medium Complexity
An image processing software applies a Horizontal Mirror Flip filter to a greyscale image represented by a 2D integer matrix int[][] pixels of size R x C (where values 0-255 represent pixel intensity). Write a program that flips the matrix horizontally in-place (swapping elements within each row) without creating a new 2D matrix.
Sample Input Matrix:
[ [10, 20, 30],
[40, 50, 60],
[70, 80, 90] ]

Expected Flipped Matrix:
[ [30, 20, 10],
[60, 50, 40],
[90, 80, 70] ]
💡 Hints & Algorithm Blueprint
  • Iterate through each row `r` from `0` to `R-1`.
  • For each row, use a two-pointer technique: `left = 0` and `right = C - 1`.
  • While `left < right`, swap `pixels[r][left]` with `pixels[r][right]`, then increment `left` and decrement `right`.
☕ Complete Java Code Reference Solution
MatrixMirrorFlip.java 
public class MatrixMirrorFlip {
    public static void main(String[] args) {
        int[][] pixels = {
            {10, 20, 30},
            {40, 50, 60},
            {70, 80, 90}
        };

        // Horizontal In-Place Mirror Flip
        for (int r = 0; r < pixels.length; r++) {
            int left = 0;
            int right = pixels[r].length - 1;
            while (left < right) {
                // Swap elements
                int temp = pixels[r][left];
                pixels[r][left] = pixels[r][right];
                pixels[r][right] = temp;
                left++;
                right--;
            }
        }

        System.out.println("Flipped Mirror Matrix:");
        for (int[] row : pixels) {
            for (int val : row) {
                System.out.printf("%4d", val);
            }
            System.out.println();
        }
    }
}
