Operations on Array Elements (For vs For-Each Loop)

Compare traditional index-controlled for loops against modern enhanced for-each loops with live execution tracing.

🔄 Traditional for Loop ✨ Enhanced for-each Loop ⚡ Element Mutation vs Read-Only

⚖️ Traditional for Loop vs. Enhanced for-each Loop

Feature Traditional for Loop Enhanced for-each Loop
Syntax for (int i = 0; i < arr.length; i++) for (int num : arr)
Index Access Explicit index variable i available No index access (only element value)
Element Mutation Can modify array: arr[i] = val; Cannot modify original array (loop variable is a copy!)
Traversal Direction Forward, backward, or step by N (e.g. i+=2) Strictly forward (0 to length-1)
Best Used For Modifying elements, multi-array indexing, reverse loops Simple read-only printing, summing, searching

1. Looping Over Primitive Arrays

LoopOperationsDemo.java
Java 17+ 
public class LoopOperationsDemo {
    public static void main(String[] args) {
        int[] numbers = {15, 42, 8, 23, 99};

        // EXAMPLE 1: Traditional for loop (Sum, Max, Element Mutation)
        System.out.println("=== Example 1: Traditional For Loop ===");
        int sum = 0;
        int max = numbers[0];

        for (int i = 0; i < numbers.length; i++) {
            sum += numbers[i];
            if (numbers[i] > max) {
                max = numbers[i];
            }
            // Modifying elements: double each value
            numbers[i] = numbers[i] * 2;
        }
        System.out.println("Total Sum (original): " + sum);
        System.out.println("Max Value: " + max);

        // EXAMPLE 2: Enhanced for-each loop (Read-Only Traversal)
        System.out.println("\n=== Example 2: Enhanced For-Each Loop ===");
        System.out.print("Doubled Elements: ");
        for (int val : numbers) {
            System.out.print(val + " ");
        }
        System.out.println();
    }
}

2. Looping Over Array of Objects (Custom Class)

Iterating over object arrays allows calling instance methods, mutating member properties, checking for null elements safely, and performing aggregations across objects.

ObjectArrayLoopDemo.java
Java 17+ 
// Custom Book Class
class Book {
    String title;
    double price;

    Book(String title, double price) {
        this.title = title;
        this.price = price;
    }
}

public class ObjectArrayLoopDemo {
    public static void main(String[] args) {
        Book[] catalog = {
            new Book("Java Programming", 50.00),
            new Book("Data Structures", 60.00),
            new Book("Clean Code", 40.00),
            null // Uninitialized slot (null safety example)
        };

        // 1. Traditional for loop: Modifying object fields (10% Discount)
        System.out.println("=== 1. Traditional For Loop (Updating Object Fields) ===");
        for (int i = 0; i < catalog.length; i++) {
            if (catalog[i] != null) { // Null Check
                catalog[i].price *= 0.90; // Mutate property inside Heap object
                System.out.println("Index [" + i + "]: " + catalog[i].title + " - Discounted: ₹" + catalog[i].price);
            }
        }

        // 2. Enhanced for-each loop: Accumulating total inventory value
        System.out.println("\n=== 2. Enhanced For-Each Loop (Aggregation & Null Safety) ===");
        double totalValue = 0.0;
        for (Book b : catalog) {
            if (b != null) {
                System.out.println("- " + b.title + " (₹" + b.price + ")");
                totalValue += b.price;
            }
        }
        System.out.println("Total Inventory Value: ₹" + totalValue);
    }
}
