Storage of Arrays in Memory

Understand how JVM manages Stack and Heap memory for arrays, reference pointers, contiguous element layout, and O(1) index math.

🧠 Stack Reference 🏔️ Heap Object 📐 Address Offset Math

🏗️ JVM Memory Architecture: Stack vs. Heap

In Java, arrays are Objects. Creating an array involves two distinct regions of JVM memory:

1. Stack Memory (Reference Variable)

  • Stores the local variable int[] arr.
  • Contains the 4-byte or 8-byte memory address pointer (reference) pointing to the Heap object.
  • Fast stack frame allocation, destroyed when method returns.

2. Heap Memory (Array Object)

  • Stores the actual Array Object with Object Header + length field + contiguous array data.
  • Allocated dynamically at runtime using new keyword.
  • Garbage Collected when no reference on Stack points to it.

💡 Key Technical Note: When are 4-Byte vs 8-Byte Memory Addresses Used in Java?

In Java, reference pointers stored on the Stack or inside Object Array slots take either 4 bytes (32-bit) or 8 bytes (64-bit) depending on JVM architecture and Compressed OOPs (Ordinary Object Pointers):

⚡ 4-Byte References (Compressed OOPs)

  • When used: Default on 64-bit JVMs when Heap size is < 32 GB (via -XX:+UseCompressedOops), and on 32-bit JVMs.
  • How it works: Java objects are aligned to 8-byte memory boundaries, so the 3 lowest bits of object addresses are always 000. By shifting addresses right by 3 bits, JVM fits a 35-bit address space (32 GB) into a 32-bit (4-byte) pointer!
  • Benefit: Cuts pointer memory overhead by 50% and optimizes CPU L1/L2 cache utilization.

🖥️ 8-Byte References (Native 64-Bit)

  • When used: On 64-bit JVMs when Heap size is > 32 GB, or when Compressed OOPs is explicitly disabled using -XX:-UseCompressedOops.
  • How it works: Stores direct, uncompressed 64-bit native virtual memory addresses.
  • Trade-off: Takes 8 bytes for every object reference (Stack variables, object reference fields, and reference array elements).

💻 Runnable Java Program Examples

1. Primitive Array Memory Demo

PrimitiveArrayMemoryDemo.java
Java 17+ 
public class PrimitiveArrayMemoryDemo {
    public static void main(String[] args) {
        // 1. Allocate primitive int array on Heap
        int[] numbers = {100, 200, 300, 400};

        // 2. Print identity hashcode (Simulates memory address reference)
        int referenceHashCode = System.identityHashCode(numbers);
        System.out.println("Stack Reference HashCode (Hex): 0x" 
                + Integer.toHexString(referenceHashCode).toUpperCase());

        // 3. Array length stored in Heap Object header
        System.out.println("Heap Object Length Field: " + numbers.length);

        // 4. Reassigning reference to null
        numbers = null; // Heap object is now eligible for Garbage Collection!
        System.out.println("Array reference is now null");
    }
}

2. Array of Objects Memory Demo

ObjectArrayMemoryDemo.java
Java 17+ 
class Student {
    int id;
    double gpa;

    Student(int id, double gpa) {
        this.id = id;
        this.gpa = gpa;
    }
}

public class ObjectArrayMemoryDemo {
    public static void main(String[] args) {
        // 1. Allocate Array of References on Heap (slots initialized to null)
        Student[] students = new Student[3];
        System.out.println("Array Container Length: " + students.length);
        System.out.println("Initial students[0] slot value: " + students[0]); // null

        // 2. Instantiate individual objects on Heap
        students[0] = new Student(101, 3.8);
        students[1] = new Student(102, 3.95);

        // 3. Print HashCodes showing distinct memory addresses
        System.out.println("Array Object Address: 0x" 
                + Integer.toHexString(System.identityHashCode(students)).toUpperCase());
        System.out.println("students[0] Instance Address: 0x" 
                + Integer.toHexString(System.identityHashCode(students[0])).toUpperCase());
        System.out.println("students[1] Instance Address: 0x" 
                + Integer.toHexString(System.identityHashCode(students[1])).toUpperCase());
        System.out.println("students[2] (Uninstantiated): " + students[2]); // null
    }
}
