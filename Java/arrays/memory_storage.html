🏗️ JVM Memory Architecture: Stack vs. Heap

In Java, arrays are Objects. Creating an array involves two distinct regions of JVM memory:

1. Stack Memory (Reference Variable)

  • Stores the local variable int[] arr.
  • Contains the 4-byte or 8-byte memory address pointer (reference) pointing to the Heap object.
  • Fast stack frame allocation, destroyed when method returns.

2. Heap Memory (Array Object)

  • Stores the actual Array Object with Object Header + length field + contiguous array data.
  • Allocated dynamically at runtime using new keyword.
  • Garbage Collected when no reference on Stack points to it.

💻 Runnable Java Program Example

ArrayMemoryDemo.java
Java 17+ 
public class ArrayMemoryDemo {
    public static void main(String[] args) {
        // 1. Allocate array on Heap
        int[] numbers = {100, 200, 300, 400};

        // 2. Print identity hashcode (Simulates memory address reference)
        int referenceHashCode = System.identityHashCode(numbers);
        System.out.println("Stack Reference HashCode (Hex): 0x" 
                + Integer.toHexString(referenceHashCode).toUpperCase());

        // 3. Array length stored in Heap Object header
        System.out.println("Heap Object Length Field: " + numbers.length);

        // 4. Reassigning reference to null
        numbers = null; // Heap object is now eligible for Garbage Collection!
        System.out.println("Array reference is now null");
    }
}

Heap Object Length Field: 4
Array reference is now null
