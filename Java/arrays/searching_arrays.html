Searching Values in Arrays

Compare Linear Search O(N) against Binary Search O(log N) and master Java's Arrays.binarySearch() utility.

🔎 Linear Search O(N) ⚡ Binary Search O(log N) 🎯 Arrays.binarySearch()

💡 Linear Search vs. Binary Search Comparison

1. Linear Search

Checks each element sequentially from index 0 to length-1 until target is found or end of array is reached.
• Array Condition: Works on ANY array (sorted or unsorted).
• Time Complexity: O(N) worst case (e.g. 1,000,000 steps for 1M elements).

2. Binary Search

Repeatedly splits search interval in half by comparing target with middle element.
• Array Condition: Array MUST BE SORTED beforehand!
• Time Complexity: O(log N) logarithmic time (e.g. max 20 steps for 1M elements!).

💻 Runnable Java Example

ArraySearchingDemo.java
Java 17+ 
import java.util.Arrays;

public class ArraySearchingDemo {
    public static void main(String[] args) {
        int[] numbers = {12, 18, 25, 33, 45, 58, 72, 89, 94};
        int target = 45;

        // 1. Custom Linear Search
        int linearIdx = linearSearch(numbers, target);
        System.out.println("Linear Search Index: " + linearIdx);

        // 2. Built-in Arrays.binarySearch()
        int binaryIdx = Arrays.binarySearch(numbers, target);
        System.out.println("Arrays.binarySearch() Index: " + binaryIdx);

        // 3. Searching non-existent value
        int missingIdx = Arrays.binarySearch(numbers, 50);
        System.out.println("Missing element 50 return value: " + missingIdx);
    }

    public static int linearSearch(int[] arr, int key) {
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] == key) return i;
        }
        return -1;
    }
}
