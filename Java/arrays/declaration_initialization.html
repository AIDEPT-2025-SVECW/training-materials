Declaration & Initialization of Primitive Arrays

Learn how to declare array reference variables, allocate heap memory with the new keyword, understand default primitive values, and use array literals.

📝 Declaration vs Instantiation ⚙️ Primitive Defaults ✨ Array Literals

📜 Syntax Breakdown: 3 Ways to Create Arrays

1. Step-by-Step Creation

Declare first, then allocate memory using new:

int[] numbers; // 1. Declare reference
numbers = new int[5]; // 2. Allocate heap

2. Combined Statement

Declare and allocate in a single line with default values:

double[] prices = new double[4];

3. Array Literal (Short hand)

Declare, allocate, and populate values at once:

int[] primes = {2, 3, 5, 7, 11};

⚙️ Automatic Default Initial Values for Primitive Types

When an array is allocated with new Data_Type[size], Java automatically populates all elements with default zero-equivalent values based on the primitive data type:

Primitive Type Bytes per Element Default Initialized Value Example Declaration
byte, short, int, long 1, 2, 4, 8 bytes 0 (or 0L for long) int[] arr = new int[3]; // [0, 0, 0]
float, double 4, 8 bytes 0.0f / 0.0 double[] arr = new double[3]; // [0.0, 0.0, 0.0]
boolean 1 byte (approx) false boolean[] arr = new boolean[3]; // [false, false, false]
char 2 bytes (UTF-16) '\u0000' (Null char / blank) char[] arr = new char[3]; // ['\0', '\0', '\0']
Object / Class Types
(e.g., Student[], String[])		 4 or 8 bytes
(Reference Pointer)		 null Student[] arr = new Student[3]; // [null, null, null]

💻 Runnable Java Program Examples

1. Primitive Arrays Initialization

PrimitiveArraysDemo.java
Java 17+ 
public class PrimitiveArraysDemo {
    public static void main(String[] args) {
        // 1. Int array with default values
        int[] numbers = new int[3];
        System.out.println("int default: " + numbers[0]); // prints 0

        // 2. Double array with default values
        double[] rates = new double[3];
        System.out.println("double default: " + rates[0]); // prints 0.0

        // 3. Boolean array with default values
        boolean[] flags = new boolean[3];
        System.out.println("boolean default: " + flags[0]); // prints false

        // 4. Direct Initialization using array literal
        char[] vowels = {'a', 'e', 'i', 'o', 'u'};
        System.out.println("Vowels count: " + vowels.length);
        System.out.println("Second vowel: " + vowels[1]);
    }
}
🖥️ Output:
int default: 0
double default: 0.0
boolean default: false
Vowels count: 5
Second vowel: e

2. Array of Objects (Custom Class Initialization)

Unlike primitives, allocating an array of objects (e.g. new Student[3]) fills all slots with null. Each index must be instantiated individually with new Student(...) or via an object array literal.

ObjectArrayInitDemo.java
Java 17+ 
// Custom Student Class
class Student {
    String name;
    int score;

    Student(String name, int score) {
        this.name = name;
        this.score = score;
    }

    void displayInfo() {
        System.out.println("Student: " + name + " | Score: " + score);
    }
}

public class ObjectArrayInitDemo {
    public static void main(String[] args) {
        // 1. Allocate Array of References (All slots default to null!)
        Student[] students = new Student[3];
        System.out.println("Default slot 0 value: " + students[0]); // prints null

        // 2. Instantiate individual Object instances into slots
        students[0] = new Student("Rahul", 88);
        students[1] = new Student("Priya", 95);
        students[2] = new Student("Amit", 79);

        System.out.println("\n--- After Object Instantiation ---");
        for (Student s : students) {
            s.displayInfo();
        }

        // 3. Array of Objects Literal Initialization (Short-hand)
        Student[] topPerformers = {
            new Student("Sneha", 99),
            new Student("Vikas", 97)
        };

        System.out.println("\n--- Object Array Literal ---");
        for (Student s : topPerformers) {
            s.displayInfo();
        }
    }
}
🖥️ Output:
Default slot 0 value: null

--- After Object Instantiation ---
Student: Rahul | Score: 88
Student: Priya | Score: 95
Student: Amit | Score: 79

--- Object Array Literal ---
Student: Sneha | Score: 99
Student: Vikas | Score: 97
