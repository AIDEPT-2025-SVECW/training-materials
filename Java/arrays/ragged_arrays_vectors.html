Ragged Arrays & Arrays as Vectors

Explore uneven multi-dimensional arrays (Ragged/Jagged Arrays) and mathematical 1D Vector operations using Java arrays.

📐 Ragged / Jagged Arrays 🔺 Pascal's Triangle 🏹 Vector Dot Product & Addition

💡 Concepts Overview

1. Ragged (Jagged) Arrays

A 2D array where each row can have a different column length.
• Declared leaving 2nd dimension empty: int[][] ragged = new int[3][];
• Instantiate each row separately:
  ragged[0] = new int[2];
  ragged[1] = new int[4];

2. Arrays as Mathematical Vectors

1D arrays represent vectors: $\mathbf{a} = \langle a_1, a_2, a_3 \rangle$.
• Vector Addition: ₹\mathbf{c}[i] = \mathbf{a}[i] + \mathbf{b}[i]$
• Dot Product: ₹\mathbf{a} \cdot \mathbf{b} = \sum (\mathbf{a}[i] \times \mathbf{b}[i])$
• Magnitude: ₹\|\mathbf{a}\| = \sqrt{\sum \mathbf{a}[i]^2}$

💻 Runnable Java Example

RaggedArraysAndVectorsDemo.java
Java 17+ 
public class RaggedArraysAndVectorsDemo {
    public static void main(String[] args) {
        // 1. Ragged Array (Uneven rows)
        int[][] ragged = new int[3][];
        ragged[0] = new int[]{1, 2};
        ragged[1] = new int[]{3, 4, 5, 6};
        ragged[2] = new int[]{7};

        System.out.println("=== Ragged Array Rows ===");
        for (int r = 0; r < ragged.length; r++) {
            System.out.print("Row " + r + " (length " + ragged[r].length + "): ");
            for (int val : ragged[r]) {
                System.out.print(val + " ");
            }
            System.out.println();
        }

        // 2. Vector Operations
        double[] vecA = {3.0, 4.0, 0.0};
        double[] vecB = {1.0, 2.0, 5.0};

        double dotProduct = 0;
        for (int i = 0; i < vecA.length; i++) {
            dotProduct += vecA[i] * vecB[i];
        }

        System.out.println("\n=== Vector Math ===");
        System.out.println("Dot Product (a • b): " + dotProduct);
    }
}
