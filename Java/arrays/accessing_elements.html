🔍 Core Rules of Accessing Array Elements

1. Zero-Based Indexing

First element is at index 0, second at 1, and the last element is always at index arr.length - 1.

2. Array Length Property

arr.length returns total number of elements. Notice it has no parentheses (unlike String.length())!

3. Boundary Violation

Accessing index < 0 or >= arr.length throws runtime error: java.lang.ArrayIndexOutOfBoundsException.

💻 Runnable Java Program Example

AccessingElementsDemo.java
Java 17+ 
public class AccessingElementsDemo {
    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        // 1. Reading first and last element
        System.out.println("First element [0]: " + numbers[0]);
        System.out.println("Last element [length-1]: " + numbers[numbers.length - 1]);

        // 2. Modifying an element value
        numbers[2] = 99;
        System.out.println("Updated index 2: " + numbers[2]);

        // 3. Handling Out-Of-Bounds exception gracefully
        try {
            int invalid = numbers[10]; // Throws exception
        } catch (ArrayIndexOutOfBoundsException e) {
            System.err.println("Caught Error: " + e.getMessage());
        }
    }
}
