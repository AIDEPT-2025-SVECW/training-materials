Scenario 1: Pluggable Multi-Provider Payment Gateway

Requirement: Create an e-commerce payment framework supporting CreditCard, UPI, and Crypto. Clients must depend solely on the abstraction, with a default receipt generation method.

PaymentProcessorDemo.java 
// The Interface Contract with Java 8 default method
interface PaymentProcessor {
    boolean processPayment(double amount);

    // Default receipt printing method available to all implementations
    default void printReceipt(double amount, String txId) {
        System.out.printf("=== RECEIPT ===%nTX ID: %s | Amount Paid: $%.2f%nStatus: SUCCESS%n==============%n", txId, amount);
    }
}

// Concrete UPI Implementation
class UpiProcessor implements PaymentProcessor {
    private String upiId;
    public UpiProcessor(String upiId) { this.upiId = upiId; }

    @Override
    public boolean processPayment(double amount) {
        System.out.println("Transferred $" + amount + " from VPA: " + upiId);
        printReceipt(amount, "UPI-" + System.currentTimeMillis());
        return true;
    }
}

Scenario 2: Vehicle Fleet with Template Method Pattern

Requirement: An abstract class FleetVehicle holds VIN, fuel, and odometer state, executes constructor initialization, and defines an unchangeable final template method dispatch() calling abstract steps.

FleetVehicleDemo.java 
abstract class FleetVehicle {
    protected String vin;
    protected double fuelLevel;

    public FleetVehicle(String vin, double fuelLevel) {
        this.vin = vin;
        this.fuelLevel = fuelLevel;
    }

    // Template Method: Final to protect workflow sequence
    public final void dispatch() {
        checkReadiness();
        igniteEngine();
        System.out.println("Vehicle " + vin + " dispatched on route.");
    }

    abstract void checkReadiness();
    abstract void igniteEngine();
}

class ElectricVan extends FleetVehicle {
    public ElectricVan(String vin, double batteryPct) { super(vin, batteryPct); }

    @Override
    void checkReadiness() { System.out.println("Battery pack health: " + fuelLevel + "%"); }

    @Override
    void igniteEngine() { System.out.println("Inverters active; motor silent."); }
}

Scenario 3: Resolving Interface Diamond Collision

Requirement: Implement both GPS and CellularModem interfaces that both provide conflicting default ping() methods.

DiamondResolutionDemo.java 
interface GPS {
    default void ping() { System.out.println("Satellite link: latency 180ms"); }
}

interface CellularModem {
    default void ping() { System.out.println("5G Cell tower: latency 20ms"); }
}

class NavigationDevice implements GPS, CellularModem {
    // Must explicitly disambiguate the conflict
    @Override
    public void ping() {
        System.out.println("--- Navigation Telemetry Ping ---");
        CellularModem.super.ping(); // Primary fast link
        GPS.super.ping();           // Fallback sync
    }
}

Scenario 4: Functional Interface Pipeline

Requirement: Process a user registration using Predicate for validation, Function for hashing password, and Consumer for sending welcome email.

RegistrationPipeline.java 
import java.util.function.*;

public class RegistrationPipeline {
    public static void main(String[] args) {
        Predicate<String> validEmail = s -> s.contains("@") && s.length() > 5;
        Function<String, String> hashPassword = p -> "HASH_" + Integer.toHexString(p.hashCode());
        Consumer<String> sendNotification = email -> System.out.println("Sent activation link to: " + email);

        String userEmail = "dev@example.com";
        String rawPass = "Secret123";

        if (validEmail.test(userEmail)) {
            String secureHash = hashPassword.apply(rawPass);
            System.out.println("Stored Hash in DB: " + secureHash);
            sendNotification.accept(userEmail);
        }
    }
}

Scenario 5: Marker Interface Security Vault

Requirement: Create a marker interface EncryptedPayload. A security gateway verifies at runtime via instanceof that payloads implement it before transmission.

SecurityVaultDemo.java 
// Marker Interface
interface EncryptedPayload { }

class FinancialTransfer implements EncryptedPayload {
    double amount = 50000;
}

class DebugMessage {
    String log = "Server ping";
}

class SecurityGateway {
    public static void transmit(Object payload) {
        if (payload instanceof EncryptedPayload) {
            System.out.println("🔒 High-security transport approved. Packet routed.");
        } else {
            System.err.println("❌ TRANSMISSION REFUSED: Payload does not implement EncryptedPayload.");
        }
    }
}
