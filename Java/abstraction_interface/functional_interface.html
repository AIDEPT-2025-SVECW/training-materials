Master the Single Abstract Method (SAM) rule: the bridge to Lambda expressions, the @FunctionalInterface annotation, and the core built-in functional interfaces in java.util.function.

1. The SAM Rule (Single Abstract Method)

A Functional Interface is an interface that contains exactly one abstract method. It is the architectural cornerstone of functional programming in Java, enabling Lambda Expressions and Method References.

✅ What It CAN Contain

  • Exactly 1 Abstract Method (the SAM).
  • Any number of default methods.
  • Any number of static methods.
  • Any number of private methods (Java 9+).
  • Abstract methods that override java.lang.Object (e.g., equals) do NOT count toward the SAM limit!

❌ What Violates the SAM Rule

  • Zero abstract methods (Marker interface).
  • Two or more abstract methods.
  • If marked with @FunctionalInterface, javac will throw an immediate compile error!
🏷️

2. The @FunctionalInterface Annotation

The @FunctionalInterface annotation is optional, but strongly recommended. It acts as an automated compiler watchdog:

Calculator.java 
@FunctionalInterface
public interface Calculator {
    // The single abstract method (SAM)
    int operate(int a, int b);

    // Default & static methods are completely allowed!
    default void log() { System.out.println("Calculating..."); }
    static void info() { System.out.println("Math operations v1.0"); }

    // java.lang.Object public methods do NOT violate SAM rule!
    @Override
    boolean equals(Object obj);
}

3. Evolution: Anonymous Inner Class vs Lambda Expression

Because a functional interface has only one abstract method, the compiler can automatically infer the method name, argument types, and return type. Lambdas eliminate verbose boilerplate:

Old Way: Anonymous Inner Class (6 Lines)

OldAnonymousStyle.java 
Calculator add = new Calculator() {
    @Override
    public int operate(int a, int b) {
        return a + b;
    }
};

Modern Way: Lambda Expression (1 Line!)

ModernLambdaStyle.java 
Calculator add = (a, b) -> a + b;
// 85% less code, faster execution, zero extra .class bytecode generated!
📦

4. The Big 4 Built-In Functional Interfaces (java.util.function)

Java 8 introduced standard functional interfaces that every developer must know for Stream processing and modern API design:

Interface Name SAM Signature Purpose Real-World Example
Predicate<T> boolean test(T t) Evaluates a boolean condition (filtering). p -> p.getAge() >= 18
Function<T, R> R apply(T t) Transforms input type T into result type R. user -> user.getEmail()
Consumer<T> void accept(T t) Consumes data; produces side-effects (printing/saving). msg -> System.out.println(msg)
Supplier<T> T get() Supplies a new value; takes no arguments (factory). () -> UUID.randomUUID()
🎮
