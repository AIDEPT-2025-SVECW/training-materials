1. What is an Interface?

An Interface in Java is a reference type, similar to a class, that can contain only constants, method signatures, default methods, static methods, and nested types. It is an agreement or contract between a service provider and its consumers.

🤝 The Contract Concept

When a class uses the implements keyword, it officially pledges: "I guarantee to provide full executable implementations for every method specified in this interface."

🔌 Plug-and-Play Architecture

Consumers write code against interface types (e.g., PaymentProcessor), allowing different implementations (PayPal, Stripe, Razorpay) to be plugged in interchangeably at runtime without changing the consumer.

🔍

2. Compiler Secrets: Implicit Modifiers

When you write code inside an interface, the Java compiler (javac) automatically injects strict keywords behind the scenes:

Variables in Interfaces

Every field declared inside an interface is automatically and implicitly:

  • public: Accessible everywhere.
  • static: Belongs to the interface itself, not any object.
  • final: Constant! Must be assigned immediately; cannot be reassigned.

Methods in Interfaces (Traditional)

Every standard method signature in an interface is automatically and implicitly:

  • public: Exposes the contract publicly to any consumer.
  • abstract: Must be provided a body by implementing classes.

3. The Golden Overriding Rule for Implementing Classes

🚨 Crucial Interview Gotcha: Why must implementing methods be declared 'public'?

In Java, an overriding method in a subclass cannot reduce the visibility of the method inherited from the parent. Since interface methods are implicitly public, any implementing class MUST explicitly specify public in its method signature!

Printer.java (Visibility Rules)
interface Printer {
    void printDocument(String doc); // implicitly public abstract
}

class LaserPrinter implements Printer {
    // ❌ COMPILE ERROR: Cannot reduce visibility from public to package-private!
    // void printDocument(String doc) { ... }

    // ✅ CORRECT: Explicit 'public' keyword is mandatory!
    @Override
    public void printDocument(String doc) {
        System.out.println("Printing high-res laser document: " + doc);
    }
}

4. Real-World Architecture: Cloud Storage Service

Demonstrating how enterprise backends utilize interfaces to allow multi-cloud infrastructure switching without modifying business logic:

CloudStorageService.java (Clean Interface)
// Pure Contract: Defines WHAT cloud operations exist
interface CloudStorageService {
    void uploadFile(String fileName, byte[] data);
    byte[] downloadFile(String fileName);
    boolean deleteFile(String fileName);
}
AwsS3Storage.java (Concrete Implementation)
// Concrete Provider A: Amazon Web Services S3
class AwsS3Storage implements CloudStorageService {
    @Override
    public void uploadFile(String fileName, byte[] data) {
        System.out.println("[AWS S3] Uploading " + fileName + " to bucket 'production-assets'");
    }

    @Override
    public byte[] downloadFile(String fileName) {
        System.out.println("[AWS S3] Fetching bytes for " + fileName);
        return new byte[1024];
    }

    @Override
    public boolean deleteFile(String fileName) {
        System.out.println("[AWS S3] Deleted object " + fileName);
        return true;
    }
}
GoogleCloudStorage.java (Concrete Implementation)
// Concrete Provider B: Google Cloud Storage
class GoogleCloudStorage implements CloudStorageService {
    @Override
    public void uploadFile(String fileName, byte[] data) {
        System.out.println("[GCS] Uploading " + fileName + " via Google Cloud Storage Client");
    }

    @Override
    public byte[] downloadFile(String fileName) {
        System.out.println("[GCS] Streaming object from GCP bucket");
        return new byte[1024];
    }

    @Override
    public boolean deleteFile(String fileName) {
        System.out.println("[GCS] Deleting object from Google Cloud");
        return true;
    }
}
StorageClient.java (Driver & Output)
// Client Application: Talks ONLY to CloudStorageService contract
public class StorageClient {
    public static void main(String[] args) {
        // Loose coupling: Depend on Interface reference!
        CloudStorageService storage = new AwsS3Storage();
        storage.uploadFile("avatar.png", new byte[512]);

        // Seamlessly switch provider with 1 line of instantiation:
        storage = new GoogleCloudStorage();
        storage.uploadFile("backup.zip", new byte[2048]);
    }
}
