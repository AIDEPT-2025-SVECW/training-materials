Multiple Inheritance & The Diamond Problem

Understand the infamous Diamond of Death from C++, why Java strictly prohibited multiple class inheritance, and how interfaces elegantly eliminate ambiguity.

💎 Diamond of Death 🛡️ Ambiguity Eradication ⚡ Java 8 Default Conflict Syntax
☠️

1. What is the "Diamond Problem"?

In object-oriented languages that support multiple class inheritance (like C++), a classic ambiguity emerges when a class inherits from two parent classes that both share a common ancestor:

Class A (defines show())
↙              ↘
Class B (overrides show()) Class C (overrides show())
↘              ↙
Class D extends B, C (Calls show()??)

1. Method Ambiguity

When an instance of D calls d.show(), which method should execute? The one from B or the one from C? The compiler has no natural way to deduce the author's intent.

2. State Duplication & Memory Havoc

If Class A had an instance variable int count, Class D inherits two separate copies of count (one via B, one via C), requiring complex pointer adjustments.

💡

2. How Java Interfaces Solved It (Pure Contracts)

Java completely disallowed multiple class inheritance (class D extends B, C is a compile error). Instead, Java introduced multiple interface inheritance (class D implements B, C).

Why There is Zero Ambiguity:

1. No State: Interfaces cannot hold non-static instance fields, so there is never duplicate state in memory.
2. No Method Body Conflict: Both Interface B and Interface C only declare abstract method signatures (void show();). They have zero implementation. Class D implements the interface and provides exactly ONE definitive method body!

Document.java (Dual Interface Implementation)
// 1. Two independent interfaces declare identical abstract signature
interface Printable {
    void display(); // Declaration only
}

interface Showable {
    void display(); // Identical declaration!
}

// 2. Class Document implements BOTH interfaces seamlessly
class Document implements Printable, Showable {
    // Exactly ONE body satisfies BOTH contracts! Zero ambiguity!
    @Override
    public void display() {
        System.out.println("Displaying document on screen & sending to printer spooler.");
    }
}
⚡

3. The Java 8+ Twist: Default Method Conflicts

Java 8 added default methods to interfaces, allowing interfaces to have method bodies! Does this bring back the Diamond Problem?

⚠️ What happens if two interfaces have the SAME default method?

If Class D implements Interface B and Interface C, and BOTH provide a default void log() method, the Java compiler raises a compile-time error:
error: class D inherits unrelated defaults for log() from types B and C

How Java Enforces Disambiguation:

Class D MUST explicitly override the conflicting method and resolve the conflict. It can provide a new implementation or choose one parent using the special syntax: InterfaceName.super.method().

EngineAndMotor.java (Colliding Defaults)
// Interface 1: Provides a default start() implementation
interface Engine {
    default void start() {
        System.out.println("Combustion engine ignited with gasoline.");
    }
}

// Interface 2: Also provides an identical default start() implementation!
interface ElectricMotor {
    default void start() {
        System.out.println("High-voltage battery engaged electric motor.");
    }
}
HybridCar.java (Explicit Disambiguation)
// HybridCar implements both - MUST override start() to resolve collision!
class HybridCar implements Engine, ElectricMotor {
    @Override
    public void start() {
        System.out.println("--- Booting Hybrid Power Controller ---");
        // Disambiguate using InterfaceName.super.methodName():
        ElectricMotor.super.start(); // Primary clean start
        Engine.super.start();        // Auxiliary combustion assist
    }
}
HybridDemo.java (Driver & Output)
public class HybridDemo {
    public static void main(String[] args) {
        HybridCar prius = new HybridCar();
        prius.start();
    }
}

/*

--- Booting Hybrid Power Controller ---
High-voltage battery engaged electric motor.
Combustion engine ignited with gasoline.
======================================================================
