super Keyword & Constructor Chaining

Master how super resolves variable shadowing, calls overridden parent methods, and triggers top-down constructor chaining during object creation.

🔑 super Keyword 🏗️ super(...) Constructor Call 🪜 Constructor Chaining ⚡ Implicit super()

🔍 The 3 Main Uses of super

1. super.variable

Accesses superclass field when shadowed by subclass field with the exact same name.

2. super.method()

Invokes superclass version of an overridden method from inside subclass code.

3. super(...)

Invokes superclass constructor. Must be the FIRST line in subclass constructor!

🏠 Real-World Indian Analogy: Multi-Floor House Construction & Secret Recipe

1. Construction Order: You cannot construct the 1st Floor (Child Constructor) before building the Ground Floor & Foundation (Parent Constructor). Java enforces this: Parent constructor ALWAYS executes first via super() before Child constructor runs!

2. Secret Recipe: When cooking Hyderabadi Biryani, the chef calls super.cookBiryani() to prepare Mom's authentic base masala, then adds extra modern saffron garnish!

Father Constructor Executed for family: " + familyName); } public void cookSpecialDish() { System.out.println("Cooking Traditional Dish with " + secretMasala); } } class SonChef extends FatherRecipe { String secretMasala = "Modern Peri Peri Masala"; // Variable Shadowing! public SonChef() { super("Sharma Family"); // MUST be 1st statement! Invokes Father Constructor System.out.println("2. Son Chef Constructor Executed!"); } @Override public void cookSpecialDish() { super.cookSpecialDish(); // Invokes Father's method System.out.println("Adding Son's garnish: " + this.secretMasala); System.out.println("Father's original masala was: " + super.secretMasala); } } public class SuperDemo { public static void main(String[] args) { SonChef chef = new SonChef(); chef.cookSpecialDish(); } }
