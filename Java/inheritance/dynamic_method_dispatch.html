Dynamic Method Dispatch & Parent References

Explore Dynamic Method Dispatch (DMD), Upcasting, Virtual Method Tables (VTable), and why field resolution uses Static Binding while method invocation uses Dynamic Binding.

⚡ Dynamic Method Dispatch ⬆️ Upcasting 📊 VTable Lookup 🔍 Field vs Method Resolution

⚙️ Technical Mechanics: Parent Ref -> Child Object

When you write: Parent obj = new Child();, two distinct types come into play:

  1. Reference Type (Parent): Evaluated at COMPILE TIME. Determines which methods/fields are visible to the compiler.
  2. Instance/Object Type (new Child()): Created at RUNTIME on Heap. Determines which overridden method implementation actually executes!

🚆 Real-World Indian Analogy: IRCTC Ticket Scanner & Passenger Types

The TTE (Train Ticket Examiner) holds a generic reference PassengerTicket ticket on his tablet. At runtime, the passenger scans their phone containing a SeniorCitizenTicket, TatkalTicket, or StudentTicket.

When TTE taps ticket.calculateFare(), JVM performs Dynamic Method Dispatch via VTable to invoke the exact fare calculation for Senior Citizen or Student based on the actual ticket instance on the passenger's screen!

Methods: Dynamic Binding (Runtime)

Overridden methods are resolved at RUNTIME using the object's Virtual Method Table (VTable). The method executed ALWAYS belongs to the actual object instance on the Heap!

Fields: Static Binding (Compile-Time)

Variables/fields are NOT polymorphic! Field access is resolved at COMPILE TIME based strictly on the Reference Type (Parent).

IRCTC_DispatchDemo.java
class IRCTC_Ticket { int bookingFee = 20; // Parent Field public void printTicketInfo() { System.out.println("Standard IRCTC Train Ticket"); } } class TatkalTicket extends IRCTC_Ticket { int bookingFee = 200; // Child Field (Shadowing) @Override public void printTicketInfo() { System.out.println("⚡ Tatkal Premium Guaranteed Ticket!"); } public void downloadTatkalPDF() { System.out.println("Downloading Tatkal PDF..."); } } public class DynamicDispatchDemo { public static void main(String[] args) { // Upcasting: Parent Reference -> Child Instance IRCTC_Ticket ticket = new TatkalTicket(); // 1. Method Invocation: Dynamic Binding (Runtime -> TatkalTicket.printTicketInfo) ticket.printTicketInfo(); // Output: ⚡ Tatkal Premium Guaranteed Ticket! // 2. Field Access: Static Binding (Compile-Time -> IRCTC_Ticket.bookingFee) System.out.println("Fee: ₹" + ticket.bookingFee); // Output: ₹20 (Parent field!) // 3. Safe Downcasting using instanceof if (ticket instanceof TatkalTicket t) { t.downloadTatkalPDF(); // Accessing child-specific method! } } }
