🏛️ java.lang.Object: The Root of All Classes

In Java, if a class does NOT explicitly use extends, the Java compiler automatically adds extends Object behind the scenes! Hence, every single object in Java inherits Object class methods.

toString()

Default: ClassName@HexHashCode (e.g. AadhaarCard@15db9742). Overriding it returns human-readable details (e.g. AadhaarCard[name=Amit, number=1234-5678-9012]).

equals(Object obj)

Default: Performs Reference Equality (same as ==). Overriding it performs Logical Content Equality (comparing actual property values).

hashCode()

Returns a 32-bit integer representing the object's hash value. Essential for hash-based data structures like HashMap and HashSet.

The Hash Code Contract

If two objects are equal according to equals(), they MUST produce the same hashCode() value. Otherwise HashMap lookup will fail!

⭐ Golden Rule of equals() & hashCode() Contract

1️⃣ If two objects are equal, their hash codes MUST be identical:
if (obj1.equals(obj2) == true) ➔ obj1.hashCode() MUST EQUAL obj2.hashCode()

2️⃣ The vice-versa is NOT necessarily true! (Hash Collision):
if (obj1.hashCode() == obj2.hashCode()) ➔ obj1.equals(obj2) can be false!

📮 Real-World Analogy: Postal PIN Code vs Exact House Address

Think of hashCode() as a Postal PIN Code (e.g., 500081) and equals() as reading the Exact Door Number & Resident Name Tag:

  • What hashCode() really tells us: It provides a quick Neighborhood / Bucket Identifier. Instead of searching through millions of houses across India, the postman uses the PIN Code to jump straight to the target neighborhood!
  • Significance of hashCode(): It gives Instant Fast Filtering. It instantly narrows down 1,000,000 items into a tiny bucket of 2 or 3 items. Then, equals() steps in to perform the exact door-to-door check.
  • Linking the Rule: If two residents live in the exact same house (equals() == true), they MUST share the exact same PIN Code (hashCode()). But two neighbors sharing PIN Code 500081 don't necessarily live in the same house (this is a Hash Collision!).

import java.util.Objects; class AadhaarCard { String holderName; String aadhaarNumber; public AadhaarCard(String holderName, String aadhaarNumber) { this.holderName = holderName; this.aadhaarNumber = aadhaarNumber; } // 1. Overriding toString() for human-readable representation @Override public String toString() { return "AadhaarCard{Name='" + holderName + "', Number='" + aadhaarNumber + "'}"; } // 2. Overriding equals() for logical content comparison @Override public boolean equals(Object obj) { if (this == obj) return true; // Same reference check if (obj == null || getClass() != obj.getClass()) return false; AadhaarCard other = (AadhaarCard) obj; // Downcasting return Objects.equals(aadhaarNumber, other.aadhaarNumber); } // 3. Overriding hashCode() to maintain Hash Contract @Override public int hashCode() { return Objects.hash(aadhaarNumber); } } public class ObjectClassDemo { public static void main(String[] args) { AadhaarCard card1 = new AadhaarCard("Priya Sharma", "9999-8888-7777"); AadhaarCard card2 = new AadhaarCard("Priya Sharma", "9999-8888-7777"); System.out.println("toString Output: " + card1); System.out.println("== Comparison: " + (card1 == card2)); // false System.out.println("equals Comparison: " + card1.equals(card2)); // true! } }
