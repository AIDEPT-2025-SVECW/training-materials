💡 Concept: What & Why Inheritance?

What is Inheritance?

Inheritance is a fundamental pillar of Object-Oriented Programming (OOP) where one class (known as the Child / Subclass / Derived Class) inherits features (fields and methods) from another class (known as the Parent / Superclass / Base Class).

Why do we need it?

Without inheritance, code would be littered with redundant duplicates. Inheritance promotes DRY (Don't Repeat Yourself) principle, enables Method Overriding (Runtime Polymorphism), and models real-world hierarchical relationships cleanly.

🏢 Real-World Indian Analogy: Sharma Ji & Sons Enterprise

Imagine Sharmaji (Father) owns a traditional sweet shop business. He has a GST_Number, a shopAddress, and a secret method makeGulabJamun(). His son, Rahul, opens a modern tech branch of the business. Rahul doesn't need to re-register a new GST or re-invent the Gulab Jamun recipe from scratch!

By inheriting from Sharmaji's Business, Rahul automatically gets the GST_Number and makeGulabJamun() for FREE, while adding his own modern methods like acceptSwiggyZomatoOrders(). Rahul's Business IS-A Sharmaji Enterprise!

⚙️ Process & Syntax of Inheritance in Java

In Java, inheritance is established using the extends keyword. A class can extend only one direct superclass.

SharmaJiEnterprise.java (Parent & Child Classes)
// Base Superclass (Parent) class FatherBusiness { String ownerName = "Ramesh Sharma"; String gstNumber = "07AAAAA0000A1Z5"; public void payGST() { System.out.println("Paying GST under GSTIN: " + gstNumber); } public void makeSpecialSweets() { System.out.println("Preparing Pure Desi Ghee Gulab Jamun!"); } } // Derived Subclass (Child) using 'extends' class SonTechBusiness extends FatherBusiness { String appName = "SharmaSweets Quick Delivery"; public void takeOnlineOrder() { System.out.println("Received order on " + appName); } } public class InheritanceDemo { public static void main(String[] args) { // Instantiate Child Object SonTechBusiness rahulBranch = new SonTechBusiness(); // Accessing Inherited Parent Members System.out.println("Owner: " + rahulBranch.ownerName); // Inherited! rahulBranch.payGST(); // Inherited! rahulBranch.makeSpecialSweets(); // Inherited! // Accessing Child's Own Members rahulBranch.takeOnlineOrder(); // Own feature! } }
