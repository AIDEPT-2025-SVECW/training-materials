1. WHY: Why Plain FileReader / FileWriter is Not Enough

Java has FileReader and FileWriter. Why do enterprise developers almost always wrap them inside BufferedReader and BufferedWriter?

🪣
The Teaspoon vs Bucket Analogy:
Suppose you need to fill a water tank in your house from a well outside.
• FileReader: Like walking to the well with a tiny teaspoon, taking one sip of water, walking back inside, and repeating 10,000 times! Every character read makes an expensive operating system disk request.
• BufferedReader: Like taking a large 20-liter bucket (an 8192-character RAM buffer) to the well once, filling the bucket in a single trip, and drinking directly from the bucket in your kitchen. It is hundreds of times faster!
Class Key Superpowers How to Construct
BufferedWriter • Holds characters in an internal 8KB buffer before writing to disk.
• newLine(): Platform-independent newline (works on Windows \r\n and Linux/Mac \n).
• flush(): Forces any pending buffered data to be written to disk immediately. 		new BufferedWriter(new FileWriter("orders.csv"))
BufferedReader • Reads characters in 8KB chunks from disk into RAM.
• readLine(): Reads an entire line of text as a String, stripping out \n or \r\n.
• Returns null when it hits End of File (EOF)! 		new BufferedReader(new FileReader("orders.csv"))
⚠️
Crucial Difference for Freshers:
• In FileInputStream (Byte Stream), the end of file (EOF) marker is -1 (an integer).
• In BufferedReader.readLine() (Character Stream), the end of file (EOF) marker is null (an object reference)!
✍️

2. Writing Text Files with BufferedWriter

Let's write a daily order ledger for a restaurant in Hyderabad on Swiggy:

SwiggyOrderWriter.java
import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;

public class SwiggyOrderWriter {

    public static void main(String[] args) {
        
        String csvFileName = "swiggy_orders_hyderabad.csv";

        // Chaining FileWriter inside BufferedWriter for maximum performance
        try (BufferedWriter writer = new BufferedWriter(new FileWriter(csvFileName))) {
            
            // 1. Write CSV Header
            writer.write("OrderID,CustomerName,ItemOrdered,BillAmount,PaymentMode");
            writer.newLine(); // Cross-platform newline (\r\n or \n)

            // 2. Write Order Records
            writer.write("SWIG-1001,Ananya Sharma,Hyderabadi Chicken Biryani,380,UPI");
            writer.newLine();

            writer.write("SWIG-1002,Vikram Reddy,Paneer Butter Masala + Naan,290,PhonePe");
            writer.newLine();

            writer.write("SWIG-1003,Deepak Verma,Masala Dosa + Filter Coffee,160,GPay");
            writer.newLine();

            writer.write("SWIG-1004,Pooja Hegde,Double Ka Meetha,120,CashOnDelivery");
            writer.newLine();

            // flush() pushes all data remaining in RAM buffer to disk
            writer.flush();

            System.out.println("✅ Swiggy daily orders ledger successfully generated: " + csvFileName);

        } catch (IOException e) {
            System.out.println("❌ Writing Error: " + e.getMessage());
        }
    }
}

3. Reading Line-by-Line with BufferedReader & Calculating Totals

Now let's read the CSV file line-by-line using BufferedReader.readLine(), parse the items, and calculate the total daily revenue in Indian Rupees (₹):

SwiggyOrderSummaryReader.java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class SwiggyOrderSummaryReader {

    public static void main(String[] args) {
        
        String csvFileName = "swiggy_orders_hyderabad.csv";
        int totalRevenue = 0;
        int totalOrders = 0;

        System.out.println("==================================================");
        System.out.println("    🍽️ SWIGGY DAILY RESTAURANT REVENUE REPORT");
        System.out.println("==================================================");

        // Chaining FileReader inside BufferedReader
        try (BufferedReader reader = new BufferedReader(new FileReader(csvFileName))) {
            
            // 1. Read first line (header) to skip it during math calculation
            String headerLine = reader.readLine();
            System.out.println("[CSV Header Skipped]: " + headerLine);
            System.out.println("--------------------------------------------------");

            String currentLine;
            // 2. Loop continues until readLine() returns null (End of File)
            while ((currentLine = reader.readLine()) != null) {
                
                // Split CSV line by comma delimiter
                String[] fields = currentLine.split(",");

                String orderId = fields[0];
                String customer = fields[1];
                String item = fields[2];
                int billAmount = Integer.parseInt(fields[3]); // Parse amount to int
                String payment = fields[4];

                System.out.printf("%-10s | %-15s | ₹ %-4d | %-12s\n", orderId, customer, billAmount, payment);

                totalRevenue += billAmount;
                totalOrders++;
            }

            System.out.println("--------------------------------------------------");
            System.out.println("Total Orders Delivered : " + totalOrders);
            System.out.println("Total Revenue Earned   : ₹ " + totalRevenue);
            System.out.println("==================================================");

        } catch (IOException e) {
            System.out.println("❌ Reading Error: " + e.getMessage());
        }
    }
}

4. Grand Master Comparison: Which Stream Should You Choose?

Criteria FileInputStream / Out FileReader / FileWriter BufferedReader / Writer
Stream Type Byte Stream (8-bit) Character Stream (16-bit) Buffered Character Stream
Best For Images (PNG/JPG), Audio, PDF, MP4, raw bytes Small text files (only simple cases) Large text files, CSV, Logs, JSON
Buffering No internal RAM buffer (unbuffered) No internal RAM buffer (direct OS calls) Yes, 8KB internal RAM buffer
Performance Moderate (Fast if custom byte[] buffer used) Slow (Every character trips disk) Blazing Fast (Batched memory reads)
Key Method read() / write(byte[]) read() / write(char) readLine() / newLine()
EOF Marker -1 -1 null (for readLine())

📌 Key Takeaways for Freshers

  • Always wrap FileReader in BufferedReader and FileWriter in BufferedWriter for performance.
  • BufferedReader.readLine() reads full lines and returns null when the file ends.
  • BufferedWriter.newLine() writes a platform-safe newline character.
  • Always flush() or let try-with-resources auto-close your buffered writer, otherwise data lingering in the RAM buffer won't be written to disk!
