Java Access Modifiers

`public` `protected` `default` (package-private) `private` Accessibility Matrix

Master how Java controls visibility and access scope for classes, constructors, fields, and methods using access modifiers: public, protected, default, and private.

📊 Java Access Modifiers Summary Matrix

Java provides 4 levels of access control to regulate visibility across classes, packages, and inheritance hierarchies:

Access Modifier Same Class Same Package Subclass (Different Package) World / Everywhere
public ✅ YES ✅ YES ✅ YES ✅ YES
protected ✅ YES ✅ YES ✅ YES (via inheritance) ❌ NO
default (no keyword) ✅ YES ✅ YES ❌ NO ❌ NO
private ✅ YES ❌ NO ❌ NO ❌ NO
1. Most Permissive
public

Accessible from any class in any package across the entire application workspace.

2. Package + Inheritance
protected

Accessible within the same package, plus subclasses located in other packages.

3. Package Scope
default

Applied when no access keyword is written. Accessible only within the defining package.

4. Most Restrictive
private

Accessible strictly within the enclosing class body. Hidden from all external classes.

🔒 `public` vs `private` Access Modifiers

1. `public` Access

Members declared as public can be accessed from any class, package, or module. Used for public API methods and constant fields.

2. `private` Access

Members declared as private are completely hidden from all external classes. They can strictly be accessed or invoked only inside the class where they are declared.

❌ Compiler Error on Private Member Access
Attempting to access a private field directly outside its defining class throws a compile-time error: balance has private access in BankAccount.
// BankAccount.java
public class BankAccount {
  public String accountNumber; // Public field
  private double balance; // Private field

  public BankAccount(String accNo, double bal) {
    this.accountNumber = accNo;
    this.balance = bal;
  }
}

// Main.java (Separate class)
BankAccount acc = new BankAccount("A101", 1000.0);
System.out.println(acc.accountNumber); // ✅ Allowed (public)
System.out.println(acc.balance); // ❌ COMPILE ERROR (private)
📦 `default` (Package-Private) & `protected` Access Modifiers

1. `default` Access (Package-Private)

When NO access modifier keyword is written before a class, variable, or method (e.g. double balance;), Java assigns default access (package-private).

  • Accessible by any class inside the SAME package.
  • BLOCKED from classes in any DIFFERENT package.

2. `protected` Access

Accessible within the same package AND by subclasses located in different packages via inheritance.

// Customer.java
public class Customer {
  String name; // default (package-private)
  protected double creditLimit; // protected

  void printDetails() { // default method
    System.out.println(name + ": " + creditLimit);
  }
}
