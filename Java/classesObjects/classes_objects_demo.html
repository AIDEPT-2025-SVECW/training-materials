📐 Class (The Blueprint)
Template

Specifies the attributes (data fields) and behaviors (methods) that all objects of this type will have. Takes no memory space until instantiated.

🚗 Object (The Instance)
Real Instance

A physical entity created from the blueprint. Holds actual state values in Heap Memory (e.g. myCar.color = "Red").

🔑 The `new` Keyword
Memory Allocator

Allocates fresh memory space in the Java Heap for an object and returns a reference memory address to the reference variable.

💡 What is a Class vs What is an Object?
📐 1. What is a Class?
Logical Blueprint

A Class is a user-defined blueprint or prototype from which objects are created. It defines variables (state) and methods (behavior).

// Class Definition (Blueprint)
class Car {
  // Attributes (States)
  String brand;
  int speed;

  // Behaviors (Methods)
  void drive() {
    System.out.println(brand + " driving!");
  }
}
🚗 2. What is an Object?
Physical Instance

An Object is an instance of a class. It is a physical entity that has State (field values), Behavior (methods), and Identity (unique memory address).

// Object Creation (Real Instances)
Car c1 = new Car(); // Instance 1
c1.brand = "Tesla";
c1.speed = 120;

Car c2 = new Car(); // Instance 2
c2.brand = "BMW";
c2.speed = 100;
🍪 Simple Real-World Analogies for Students
1. Cookie Cutter vs Cookie
The Cookie Cutter is the Class. The actual delicious Cookies baked from it are the Objects!
2. House Blueprint vs Built House
The paper architectural blueprint is the Class. The physical houses built on 1st & 2nd street are the Objects!
🎯 Why Do We Need Classes & Objects in Java?
1. Real-World Modeling
OOP Mindset

Real-world applications deal with real concepts (e.g., Bank Accounts, Students, E-Commerce Products). Classes let software developers model these exact entities cleanly.

2. Massive Code Reusability
DRY Principle

Write the Student class blueprint ONCE. Then create 10,000 student objects without duplicating variables or method logic!

3. Data Encapsulation
Modularity & Security

Bundles data fields (`balance`) together with the methods that operate on them (`deposit()`, `withdraw()`), protecting data from unauthorized external modification.

💻 How to Use Classes & Objects in Java (3 Easy Steps)
Step 1: Declare the Class
class Keyword

Define attributes (variables) & behaviors (methods).

class Student {
  String name;
  double gpa;
  void study() { ... }
}
Step 2: Instantiate with `new`
new Keyword

Allocates memory in Heap & returns reference.

// ClassName refVar = new ClassName();
Student s1 = new Student();
Step 3: Access via Dot Operator
Dot (.) Operator

Access attributes or call methods on the object.

s1.name = "JP";
s1.gpa = 3.9;
s1.study(); // Invokes method
🧠 Stack vs Heap Memory Breakdown

When you execute Car myCar = new Car();:

  • Stack Memory: Holds the reference variable myCar (which contains the memory address pointer 0x401).
  • Heap Memory: Holds the actual physical Object data (brand: "Tesla", speed: 120) created at address 0x401.

🎯 Classes & Objects Self-Assessment Quizzes
1. What is a Class in Java?
A) A blueprint or template from which objects are created
B) A physical instance allocated in heap memory
C) A primitive data type like int or float
🎉 Correct! A class is a logical blueprint that defines attributes and behaviors. Objects are physical instances created from it.
2. Which Java keyword is used to instantiate an object in heap memory?
A) create
B) new
C) alloc
🎉 Correct! The new keyword allocates memory in the Heap for a fresh object instance and returns its reference address.
3. How do you access a field or invoke a method on an object reference `myCar`?
A) myCar->speed
B) myCar.speed
C) myCar::speed
🎉 Correct! In Java, member variables and methods are accessed using the dot (.) operator.
4. Where are actual Object instances stored in Java memory?
A) Heap Memory
B) Stack Memory
C) Method Register
🎉 Correct! All object instances reside in Heap Memory, while local reference variables holding their memory pointers reside in Stack Memory.
