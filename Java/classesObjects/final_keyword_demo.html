1. final Variables (Primitives, Constants & Blank Finals)
▲

A final variable can be assigned exactly once. Once initialized, its value cannot be modified.

Types of final Variables:

  • Compile-time Constants: Declared as public static final double PI = 3.14159;. By convention, constant names are written in ALL_CAPS with underscores.
  • Blank final Instance Variables: A final field that is NOT initialized at its declaration site. It MUST be initialized inside every constructor before object creation finishes.
  • Local final Variables: Declared inside method bodies or loops to enforce read-only variables.
class Employee {
  public static final String COMPANY = "TechCorp"; // Static Constant
  private final int empId; // Blank final instance variable

  public Employee(int id) {
    this.empId = id; // Initialized in constructor (Allowed ONCE)
  }
}
2. final Methods (Preventing Method Overriding)
▼

Declaring a method final prevents subclasses from providing their own implementation (overriding it).

Why use final Methods?

  • Security & Consistency: Ensure core algorithms (e.g., password hashing, payment verification) cannot be altered by derived classes.
  • Performance (JIT Inlining): Historically, JVM compilers could inline final methods because call targets are guaranteed not to change.
class BankAccount {
  public final void printTermsAndConditions() {
    System.out.println("Standard Legal Terms v1.0");
  }
}

class SavingsAccount extends BankAccount {
  // Attempting to override final method:
  //@Override
  // public void printTermsAndConditions() {} ❌ Compile Error!
}
3. final Classes (Preventing Class Inheritance)
▼

A class marked as final cannot be inherited or extended by any other class.

Key Highlights:

  • All methods inside a final class are implicitly final because no subclass can ever override them.
  • Standard Java Library classes like java.lang.String, java.lang.Integer, and java.lang.Math are declared final for security and immutability.
public final class ImmutableToken {
  private final String tokenVal;
  public ImmutableToken(String val) { this.tokenVal = val; }
}

// Compilation Error: Cannot inherit from final 'ImmutableToken'
// class SubToken extends ImmutableToken {} ❌
4. The 3 F's Matrix: final vs finally vs finalize()
▼

A classic Java interview question! Although they sound similar, they serve completely different purposes:

Term Category Purpose & Usage
final Access Modifier / Keyword Used to declare constants, prevent method overriding, and disable class inheritance.
finally Exception Block A block associated with try-catch that ALWAYS executes regardless of whether an exception occurs (used for cleanup).
finalize() Object Method A method defined in java.lang.Object called by the Garbage Collector before destroying an object. (Deprecated in Java 9+).
