Java Installation, Environment Variables & CLI vs IDE

Master JDK installation, verify system paths (`JAVA_HOME`, `PATH`, `CLASSPATH`), run Java programs manually via Command Line without an IDE, and understand how IDEs simplify development.

📥

1. JDK Installation & Verification

To write and run Java code, you need the JDK (Java Development Kit), which includes both the Java Compiler (javac) and the Java Runtime Environment (java JVM). Popular free JDK distributions include Eclipse Temurin (Adoptium), Oracle JDK, and Amazon Corretto.

Interactive CLI Verification Terminal:

C:\Users\Student> java -version
openjdk version "21.0.2" 2024-01-16 LTS
OpenJDK Runtime Environment Temurin-21.0.2+13 (build 21.0.2+13-LTS)
OpenJDK 64-Bit Server VM Temurin-21.0.2+13 (build 21.0.2+13-LTS, mixed mode, sharing)
⚙️

2. Environment Variables: JAVA_HOME, PATH & CLASSPATH

📁 JAVA_HOME

Points to the root directory where the JDK is installed (e.g. C:\Program Files\Java\jdk-21). Build tools like Maven, Gradle, and IDEs use this variable to locate Java.

🛣️ PATH

Tells your OS command line where to find executable binaries. Adding %JAVA_HOME%\bin lets you run javac and java from any command prompt directory.

📦 CLASSPATH

Tells the JVM where to look for user-defined .class bytecode files and external third-party .jar library dependencies during execution.

OS Setup Instructions (Select OS):

# Setting JAVA_HOME via CMD (Administrator):
setx /M JAVA_HOME "C:\Program Files\Java\jdk-21"
# Verify JAVA_HOME in CMD:
echo %JAVA_HOME%
# Output:
C:\Program Files\Java\jdk-21
# Add to ~/.zshrc or ~/.bashrc:
export JAVA_HOME=$(/usr/libexec/java_home)
export PATH=$JAVA_HOME/bin:$PATH
# Reload terminal profile & verify:
source ~/.zshrc
echo $JAVA_HOME

3. Running Java WITHOUT an IDE (Manual CLI Workflow)

Before using complex IDEs, every Java developer should understand the raw 2-step process of compilation and execution using a basic text editor (Notepad) and Command Line:

1. Create text file named 'HelloWorld.java':
public class HelloWorld {
  public static void main(String[] args) {
    System.out.println("Hello World from Command Line!");
  }
}
🚀

4. What is an IDE & How It Simplifies Life

An IDE (Integrated Development Environment) like IntelliJ IDEA, Eclipse, or VS Code bundles a source code editor, build automation, compiler, and debugger into a single graphical application.

Feature / Task Manual CLI Workflow (Notepad + Terminal) Modern IDE Workflow (IntelliJ / Eclipse / VS Code)
Writing Code Plain text editor with no syntax highlighting or autocomplete. Smart Auto-Complete (IntelliSense), syntax coloring, auto-importing.
Compilation Must switch to Terminal & manually run javac Main.java. Auto-compiled in background upon typing/saving. Instant red squiggly lines for errors.
Execution Must type java Main in terminal. 1-Click ▶️ Run Button or keyboard shortcut (`Shift + F10`).
Debugging Using print statements (`System.out.println`). Visual Breakpoints, memory variable inspection, step-over / step-into execution.
🛠️

5. Troubleshooting Guide (Common Setup Errors)

1. 'javac' is not recognized as an internal or external command
▲

Cause: The OS cannot locate the javac.exe compiler binary because JDK's bin folder is missing from system PATH.

Resolution:

  1. Set JAVA_HOME to your JDK root folder e.g., C:\Program Files\Java\jdk-21.
  2. Add %JAVA_HOME%\bin to System Environment Variable PATH.
  3. Close and reopen Command Prompt/Terminal, then re-verify with javac -version.
2. Error: Could not find or load main class HelloWorld
▼

Cause: You are executing `java HelloWorld.class` (with `.class` extension) or running `java` from a directory where `HelloWorld.class` does not exist.

Resolution:

  • Do NOT include the `.class` extension! Run java HelloWorld (just the class name).
  • Ensure class name inside file matches the filename exactly (case-sensitive).
3. UnsupportedClassVersionError: Has been compiled by a more recent version
▼

Cause: You compiled the code using a higher JDK version (e.g., JDK 21), but attempted to run it on a lower JRE runtime version (e.g., Java 11).

Resolution:

Update your runtime JRE version to match or exceed the compiler JDK version, or compile with --release flag (e.g., javac --release 11 Main.java).
