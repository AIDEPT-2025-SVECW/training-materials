MODULE 07

React Synthetic Events & Handlers

Master event handling in React: Synthetic Events, inline vs callback functions, passing parameters to handlers, and syncing events with state.

🇮🇳 Indian Real-World Context: Stadium IPL Scoreboard Control
The third umpire signals a boundary. The stadium scoreboard operator presses the "+4 Runs" button. An event handler captures the click event, passes 4 as an argument to the state updater, and updates the stadium LED screen!

1. React Synthetic Events

React wraps native browser events in a cross-browser wrapper called SyntheticEvent. Synthetic events ensure consistent event behavior across Chrome, Safari, Firefox, and Edge.

2. Event Handlers & Passing Arguments

To pass arguments to an event handler, wrap the function call inside an anonymous arrow function:

import React, { useState } from 'react';

export default function IPLScoreboard() {
  const [runs, setRuns] = useState(140);
  const [wickets, setWickets] = useState(3);

  // Event handler receiving an argument
  const handleAddRuns = (numRuns, event) => {
    console.log("Event triggered by button:", event.target);
    setRuns(prev => prev + numRuns);
  };

  return (
    <div className="scoreboard">
      <h2>🏏 MI vs CSK Scoreboard</h2>
      <h1>{runs} / {wickets}</h1>
      
      {/* Arrow function passes custom arguments */}
      <button onClick={(e) => handleAddRuns(1, e)}>+1 Single</button>
      <button onClick={(e) => handleAddRuns(4, e)}>+4 Four!</button>
      <button onClick={(e) => handleAddRuns(6, e)}>+6 Sixer!</button>
      <button onClick={() => setWickets(w => w + 1)}>Wicket!</button>
    </div>
  );
}

3. Standard Event Handlers: onChange & onSubmit

function QuickLoginForm() {
  const [email, setEmail] = useState('');

  const handleSubmit = (e) => {
    e.preventDefault(); // Prevents default page refresh on form submit
    alert("Logging in with: " + email);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input 
        type="email" 
        value={email} 
        onChange={(e) => setEmail(e.target.value)} 
        placeholder="Enter email..."
      />
      <button type="submit">Login</button>
    </form>
  );
}
⚠️ Critical Pitfall (Immediate Execution): Never call the handler directly inside onClick: onClick={handleAddRuns(4)} will execute immediately when the component renders! Always wrap it in an arrow function: onClick={() => handleAddRuns(4)}.
