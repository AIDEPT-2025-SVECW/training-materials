MODULE 08

Conditional Rendering Patterns

Master rendering UI elements dynamically using ternary operators, short-circuit logical && operators, if/else blocks, and state triggers.

🇮🇳 Indian Real-World Context: GooglePay UPI Payment Status Screen
When sending money via GooglePay UPI, the app dynamically renders different UI screens based on payment state: if state is SUCCESS, display a green check tick; if PENDING, show an animated amber clock; if FAILED, display a red retry banner.

1. The 3 Core Conditional Rendering Techniques

Technique A: If / Else Statements (Early Return)

function PaymentStatus({ status }) {
  if (status === 'SUCCESS') {
    return <div className="success">✅ UPI Transaction Successful! ₹500 Sent.</div>;
  }
  if (status === 'PENDING') {
    return <div className="pending">⏳ Bank Processing... Please Wait.</div>;
  }
  return <div className="failed">❌ Payment Failed. Check UPI PIN.</div>;
}

Technique B: Ternary Operator (condition ? A : B)

function UserBadge({ isLoggedIn, userName }) {
  return (
    <div className="header">
      {isLoggedIn ? (
        <span>🙏 Welcome back, {userName}!</span>
      ) : (
        <button>Login to Swiggy</button>
      )}
    </div>
  );
}

Technique C: Short-Circuit Logical && (condition && element)

function ShoppingCart({ itemCount }) {
  return (
    <div>
      <h3>🛒 Your Cart</h3>
      {/* Renders badge ONLY if itemCount > 0 */}
      {itemCount > 0 && (
        <span className="badge-count">{itemCount} Items Selected</span>
      )}
    </div>
  );
}
⚠️ Logical && Falsy Trap (The "0" Bug): In JavaScript, 0 && <Component /> evaluates to the number 0! The browser will literally render the number 0 on screen! Always convert numbers to booleans: itemCount > 0 && <Component />.
