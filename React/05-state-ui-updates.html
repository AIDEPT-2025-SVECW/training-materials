MODULE 05

State Management & Component Re-rendering

Master internal component state using the useState hook, state vs props differences, and immutable object/array state updates.

🇮🇳 Indian Real-World Context: PayTM Wallet Balance
Your PayTM Wallet balance is internal component State. Every time you scan a merchant UPI QR code and spend ₹50, calling setBalance() updates state, instantly triggering a component re-render that displays your new wallet total on screen.

1. State vs Props Comparison

Feature Props State
Ownership Passed down from Parent Created and owned inside Component
Mutability Read-Only (Immutable) Mutable via setter function (setX)
Re-render Trigger Re-renders when Parent passes new props Re-renders when setter function is called

2. The useState Hook

The useState hook returns an array with exactly two elements: the current state value and a state updater function.

import React, { useState } from 'react';

export default function PaytmWallet() {
  // State initialization: initial balance is ₹1200
  const [balance, setBalance] = useState(1200);

  const handlePayChai = () => {
    // Updating state functionally
    setBalance(prevBalance => prevBalance - 20);
  };

  return (
    <div className="wallet-card">
      <h3>📱 PayTM Wallet: ₹{balance}</h3>
      <button onClick={handlePayChai}>☕ Pay Chai (₹20)</button>
    </div>
  );
}

3. Immutably Updating Objects & Arrays in State

In React, state should never be mutated directly (e.g. user.name = 'Rahul' or items.push('Chai')). Always create a copy using the ES6 Spread Operator ...:

// 1. Updating Objects in State
const [userProfile, setUserProfile] = useState({ name: "Rahul", city: "Mumbai" });
const updateCity = () => {
  setUserProfile(prev => ({ ...prev, city: "Bengaluru" }));
};

// 2. Updating Arrays in State
const [cart, setCart] = useState(["Samosa", "Jalebi"]);
const addItem = () => {
  setCart(prev => [...prev, "Masala Chai"]); // Spread operator creates new array
};
⚠️ Direct Mutation Warning: Mutating state directly (e.g., cart.push('Chai')) modifies memory reference in-place. React won't detect reference changes and will NOT re-render the screen!
