MODULE 10

React Forms & Controlled Components

Master handling user inputs, form elements (text, select, checkbox, radio), state synchronization, submit handlers, and live input validation.

🇮🇳 Indian Real-World Context: IRCTC Tatkal Booking Form
On IRCTC, every input field—Passenger Name, Age, Berth Preference, and Senior Citizen Checkbox—is a Controlled Component. As you type your name or pick Lower Berth, React state updates instantaneously, validating Tatkal quota eligibility before you click Confirm Booking.

1. What is a Controlled Component?

In HTML, form elements like <input> maintain their own internal state. In React, a Controlled Component forces the input value to be driven directly by React state. The state becomes the "single source of truth".

2. Multi-Input Form Handling Pattern

import React, { useState } from 'react';

export default function IRCTCBookingForm() {
  const [formData, setFormData] = useState({
    passengerName: '',
    berthPref: 'LOWER',
    isSeniorCitizen: false,
    foodOption: 'VEG'
  });

  // Universal onChange handler using ES6computed property names
  const handleChange = (e) => {
    const { name, value, type, checked } = e.target;
    setFormData(prev => ({
      ...prev,
      [name]: type === 'checkbox' ? checked : value
    }));
  };

  const handleSubmit = (e) => {
    e.preventDefault(); // Prevents page reload
    if (!formData.passengerName.trim()) {
      alert("Passenger Name is required!");
      return;
    }
    alert(\`Tatkal Ticket Booked for \${formData.passengerName} (\${formData.berthPref} Berth)\`);
  };

  return (
    <form onSubmit={handleSubmit} className="form-box">
      <h3>🚆 IRCTC Tatkal Passenger Details</h3>
      
      <div>
        <label>Passenger Name:</label>
        <input 
          type="text" 
          name="passengerName" 
          value={formData.passengerName} 
          onChange={handleChange} 
        />
      </div>

      <div>
        <label>Berth Preference:</label>
        <select name="berthPref" value={formData.berthPref} onChange={handleChange}>
          <option value="LOWER">Lower Berth</option>
          <option value="MIDDLE">Middle Berth</option>
          <option value="UPPER">Upper Berth</option>
          <option value="SIDE_LOWER">Side Lower</option>
        </select>
      </div>

      <div>
        <label>
          <input 
            type="checkbox" 
            name="isSeniorCitizen" 
            checked={formData.isSeniorCitizen} 
            onChange={handleChange} 
          /> Senior Citizen Concession
        </label>
      </div>

      <button type="submit">Proceed to PayTM Payment</button>
    </form>
  );
}
⚠️ Controlled Component Warning: Always initialize state with a non-null string (e.g., ''). If initialized as undefined or null, React treats it as an uncontrolled input and logs a console warning when it later switches to controlled!
