MODULE 11

React Router & Single Page Routing

Master client-side SPA routing: BrowserRouter, Routes, Route, Link vs NavLink, dynamic route parameters, and view navigation.

🇮🇳 Indian Real-World Context: Namma Metro Route Navigation
Navigating a Single Page Application with React Router is like taking the Namma Metro between stations (/station/majestic → /station/mg-road). You switch platform views instantly inside the train network without exiting the station (without making a full page HTTP reload to the web server!).

1. Installing & Setting Up React Router v6

# Install React Router v6 package
npm install react-router-dom

2. Configuring Routes & Dynamic Route Params

import React from 'react';
import { BrowserRouter, Routes, Route, Link, NavLink, useParams } from 'react-router-dom';

// 1. Station Component reading dynamic route parameters (:stationName)
function MetroStationView() {
  const { stationName } = useParams();
  return (
    <div className="station-page">
      <h3>🚉 Station View: {stationName.toUpperCase()}</h3>
      <p>Next Train Arriving in 3 Mins on Platform 2.</p>
    </div>
  );
}

// 2. Navigation Bar using NavLink for active styling
function NavigationBar() {
  return (
    <nav className="nav-bar">
      <NavLink to="/" className={({ isActive }) => isActive ? 'active' : ''}>
        Home Interchange
      </NavLink> | 
      <NavLink to="/station/majestic">Majestic</NavLink> | 
      <NavLink to="/station/mg-road">MG Road</NavLink>
    </nav>
  );
}

// 3. Main Router Entry App Component
export default function MetroApp() {
  return (
    <BrowserRouter>
      <NavigationBar />
      <Routes>
        <Route path="/" element={<h2>🚆 Welcome to Namma Metro Network</h2>} />
        <Route path="/station/:stationName" element={<MetroStationView />} />
        <Route path="*" element={<h2>404 - Station Not Found</h2>} />
      </Routes>
    </BrowserRouter>
  );
}
⚠️ Never Use Standard <a href="..."> Tags for SPA Routes! Using standard HTML <a href="/about"> forces a full page browser refresh, resetting all React component state! Always use React Router's <Link to="/about"> component.
