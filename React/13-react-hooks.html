MODULE 13

React Hooks & Side-Effect Lifecycles

Master the Golden Rules of Hooks, useEffect lifecycles (mount, update, unmount cleanup), and building reusable custom hooks.

🇮🇳 Indian Real-World Context: Monsoon Rain Tracker API
The useEffect hook is like subscribing to a live Monsoon Weather Alert service. Whenever the selected Indian city changes (dependency array update), the effect triggers a new API request, and unsubscribes (cleanup function) when the user navigates away!

1. The 2 Golden Rules of Hooks

  • Rule 1: Only call Hooks at the Top Level of your React component function. Never call hooks inside loops, nested functions, or if conditions!
  • Rule 2: Only call Hooks from React Function Components or Custom Hooks (never call from regular JS functions).

2. Understanding useEffect & Dependency Arrays

import React, { useState, useEffect } from 'react';

export default function MonsoonTracker() {
  const [city, setCity] = useState('Mumbai');
  const [rainData, setRainData] = useState(null);

  useEffect(() => {
    console.log(\`[Effect Run] Fetching weather for \${city}...\`);
    
    // Simulate API fetch request
    const timer = setTimeout(() => {
      setRainData({ city, precipitation: Math.floor(Math.random() * 80) + 10 });
    }, 500);

    // Cleanup Function (runs before next effect execution or component unmount)
    return () => {
      console.log(\`[Cleanup] Cancelling pending fetch timer for \${city}\`);
      clearTimeout(timer);
    };
  }, [city]); // Effect triggers ONLY when 'city' state value changes

  return (
    <div className="weather-card">
      <h3>🌧️ India Monsoon Live Tracker</h3>
      <p>Active City: <strong>{city}</strong></p>
      {rainData && <p>Precipitation: {rainData.precipitation} mm</p>}
      
      <button onClick={() => setCity('Mumbai')}>Mumbai</button>
      <button onClick={() => setCity('Bengaluru')}>Bengaluru</button>
      <button onClick={() => setCity('Cherrapunji')}>Cherrapunji</button>
    </div>
  );
}

3. Basic Custom Hook Pattern

// Custom Hook: useWindowWidth.js
function useWindowWidth() {
  const [width, setWidth] = useState(window.innerWidth);

  useEffect(() => {
    const handleResize = () => setWidth(window.innerWidth);
    window.addEventListener('resize', handleResize);
    return () => window.removeEventListener('resize', handleResize);
  }, []); // Empty array = run once on mount

  return width;
}
⚠️ Infinite Re-render Loop Warning: Calling state updater functions (e.g. setCount(count + 1)) directly inside useEffect without an appropriate dependency array will trigger an infinite loop!
