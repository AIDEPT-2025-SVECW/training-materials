MODULE 14

Sharing Data & Lifting State Up

Master component communication: child-to-parent data flow via callback functions, lifting state up, and sharing state between sibling components.

🇮🇳 Indian Real-World Context: Housing Society Maintenance Fund
Flat 101 and Flat 102 (Sibling components) cannot send money directly to each other. Instead, state is lifted up to the Gokuldham Housing Society President (Parent component). When Flat 101 pays ₹2000, it invokes a callback function that updates the total society fund in parent state!

1. The "Lifting State Up" Principle

When two or more sibling components need to reflect the same changing data, you should lift the shared state up to their closest common ancestor parent component.

import React, { useState } from 'react';

// Sibling 1: Payment Button Component
function FlatPaymentCard({ flatNo, onPayMaintenance }) {
  return (
    <div className="card" style={{ margin: '8px 0', border: '1px solid #cbd5e1', padding: '12px' }}>
      <h4>🏠 Flat {flatNo}</h4>
      <button onClick={() => onPayMaintenance(2000)}>Pay ₹2000 Maintenance</button>
    </div>
  );
}

// Parent Component owning shared state
export default function GokuldhamSociety() {
  const [totalFund, setTotalFund] = useState(0);

  // Callback function passed to children
  const handleCollectMoney = (amount) => {
    setTotalFund(prevFund => prevFund + amount);
  };

  return (
    <div className="society-box">
      <h2>🏢 Gokuldham Society Account</h2>
      <h1>Total Funds Collected: ₹{totalFund}</h1>
      
      {/* State shared between sibling components */}
      <FlatPaymentCard flatNo="101" onPayMaintenance={handleCollectMoney} />
      <FlatPaymentCard flatNo="102" onPayMaintenance={handleCollectMoney} />
    </div>
  );
}
⚠️ Prop Drilling Warning: If state needs to be passed down through 5+ levels of intermediate components, lifting state up causes Prop Drilling. For deeply nested global state (e.g. user authentication), consider React Context API or Zustand.
