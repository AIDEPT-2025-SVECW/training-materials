MODULE 09

Rendering Lists & The Key Prop

Master iterating JavaScript arrays with map(), rendering lists of components, understanding DOM reconciliation, and avoiding key prop bugs.

🇮🇳 Indian Real-World Context: Zomato Restaurant Feed
When Zomato loads nearby restaurants, it fetches an array of restaurant objects from the database. React iterates through this array using map(), assigning each restaurant's unique database ID (res_101) to the key prop so React knows exactly which card to re-render when ratings update.

1. Iterating Arrays with Array.prototype.map()

In React, we use the standard JavaScript map() method to transform an array of raw data objects into an array of JSX elements:

import React from 'react';

export default function ZomatoFeed() {
  const restaurants = [
    { id: 'res_101', name: 'Saravana Bhavan', cuisine: 'South Indian', rating: 4.6 },
    { id: 'res_102', name: 'Haldiram\'s', cuisine: 'North Indian Sweets', rating: 4.4 },
    { id: 'res_103', name: 'Bawarchi Biryani', cuisine: 'Hyderabadi', rating: 4.7 }
  ];

  return (
    <div className="restaurant-feed">
      <h2>🛵 Top Restaurants Near You</h2>
      <div className="grid">
        {restaurants.map((res) => (
          // The key prop MUST be passed at the top-level element returned by map
          <div key={res.id} className="res-card">
            <h3>{res.name}</h3>
            <p>Cuisine: {res.cuisine} | ⭐ {res.rating}</p>
          </div>
        ))}
      </div>
    </div>
  );
}

2. Why is the `key` Prop Crucial?

Keys give React elements a stable identity. When items in a list are re-ordered, added, or removed, the key helps React Reconciliation determine which items actually changed versus which remained unchanged. This prevents unnecessary DOM re-creations.

⚠️ Anti-Pattern Warning (Array Index as Key): Avoid using array index (key={index}) for lists where items can be re-ordered, filtered, or deleted! Using index causes state glitches in child inputs. Always use a unique ID (e.g. res.id or item.uuid).
