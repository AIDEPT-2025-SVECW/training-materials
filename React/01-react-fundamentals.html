ReactJS Fundamentals & Root Rendering

Master the core building blocks of ReactJS: why React exists, application layout, DOM elements rendering, and the Virtual DOM engine.

🇮🇳 Indian Real-World Context: The Dhabha Kitchen
Imagine sitting at a busy Highway Dhaba. Traditional HTML is like serving a fixed thali: if you order one extra Roti, the kitchen cooks an entirely new thali set from scratch! ReactDOM is like a modern smart waiter: when you request an extra Roti, he only updates that specific small bowl on your table without touching the rest of the meal.

1. Introduction to ReactJS

React is a declarative, efficient, and flexible JavaScript library created by Meta (Facebook) for building user interfaces. Instead of manually manipulating the browser DOM using document.getElementById(), React allows developers to build component-based architectures where the UI automatically updates whenever application data changes.

2. React Application Structure

A standard modern React application initialized with Vite or Create React App follows a structured file hierarchy:

  • index.html: The single HTML root file containing <div id="root"></div>.
  • src/main.jsx (or index.js): The JavaScript entry point that connects React to the HTML DOM.
  • src/App.jsx: The root component representing the top of your application component tree.

3. The Virtual DOM & ReactDOM Root Rendering

Direct DOM manipulation is slow because browsers perform expensive layout recalculations. React uses a lightweight in-memory representation called the Virtual DOM. When state updates, React creates a new Virtual DOM tree, performs a fast Diffing Algorithm against the previous Virtual DOM, and updates only the changed elements in the real DOM.

// Modern React 18 Root Rendering Architecture
import React from 'react';
import ReactDOM from 'react-dom/client';

// 1. Target the root container div in HTML
const container = document.getElementById('root');

// 2. Create a React 18 Root
const root = ReactDOM.createRoot(container);

// 3. Render React Element to Root
root.render(
  <h1>🙏 Namaste React World!</h1>
);
⚠️ Developer Pitfall (React 18 vs React 17): In React 18, legacy ReactDOM.render(<App />, container) is deprecated. Always use ReactDOM.createRoot(container).render(<App />) for Concurrent Rendering support.
