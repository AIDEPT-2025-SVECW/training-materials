MODULE 03

React Components & Composition

Master modular architecture: Function vs Class components, nesting components, file layout, and ES6 modular imports/exports.

🇮🇳 Indian Real-World Context: Tata Motors Automobile Assembly
Instead of manufacturing a Tata Nexon SUV out of a single lump of steel, Tata Motors builds independent component units: Engine Component, Dashboard Component, and Wheel Components. These independent modules are composed together to build the final car!

1. What are Components?

Components are the independent, reusable building blocks of any React application. They act like JavaScript functions: they accept inputs (called props) and return React elements describing what should appear on screen.

2. Function Components vs Class Components

Modern React uses Function Components with Hooks exclusively. Class components were the legacy way prior to React 16.8.

// 1. Function Component (Modern Standard)
function EngineSpec() {
  return <p>⚡ Revotron 1.2L Turbocharged Engine</p>;
}

// 2. Class Component (Legacy Overview)
import React, { Component } from 'react';
class TransmissionSpec extends Component {
  render() {
    return <p>⚙️ 6-Speed AMT Transmission</p>;
  }
}

3. Nesting & Component Composition

Components can be nested inside other components to build complex UI hierarchies:

function CarHeader() {
  return <h2>🚘 Tata Nexon Assembly Line</h2>;
}

function CarFooter() {
  return <p>© 2026 Tata Motors Ltd. Made in India.</p>;
}

// Parent Assembly Component
export default function TataNexonApp() {
  return (
    <div className="assembly-card">
      <CarHeader />
      <EngineSpec />
      <CarFooter />
    </div>
  );
}

4. Component File Structure & ES6 Modular Exports

In real-world projects, every component resides in its own file inside the src/components/ directory:

// File: src/components/Button.jsx
export function PrimaryButton({ label }) {
  return <button className="btn-primary">{label}</button>;
}

// Default export
export default function Card({ title }) {
  return <div className="card">{title}</div>;
}

// File: src/App.jsx
import Card, { PrimaryButton } from './components/Button';

⚠️ Strict Component Naming Rule: Component names MUST always start with a Capital Letter (e.g. <CarHeader />). If named in lowercase <carHeader />, React will treat it as a standard HTML element and fail to invoke your component function!
