HTTP is Stateless — explained with a simple movie analogy 🎬

Imagine Surya and Asin from Ghajini trying to communicate. The analogy helps us understand why a web server does not automatically remember every request.

🎬 Movie analogy

Surya and Asin meet and exchange information. But imagine that after every interaction, Surya forgets the previous conversation.

So every time Asin meets him, she has to provide some information again.

🌐 HTTP analogy

A browser sends an HTTP request to a server. The server sends a response. Normally, the server does not automatically remember the previous request.

That is what we mean by HTTP being stateless.

2. So how does a website remember us? 🍪

HTTP itself is stateless, but websites can use additional mechanisms. One very common mechanism is a cookie.

Cookie = a small piece of information stored by the browser

Think of it like Asin giving Surya a small identity card: “When you see this ID, remember that this is me.”
