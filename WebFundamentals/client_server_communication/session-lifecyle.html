🌐 Web analogy

The server creates a session and gives the browser a Session ID.

The browser sends that ID with later requests, allowing the server to find the stored session data.

2. The Most Important Idea

Cookie ≠ Session

In a common web application:

🍪 Cookie → browser stores a Session ID

🗄️ Session → server stores information associated with that ID

🔁 Next request → browser sends the Session ID → server finds the session → user is recognized
