🚨 Step 2 — Fresher Traps & Gotchas

Directives Comparison: Avoid Common Mistakes

RUN vs. CMD (The Most Common Exam Question!)

• RUN (Build-Time): Executed while building the Docker Image (e.g. RUN npm install or RUN apt-get update). Commits a new image layer.
• CMD (Runtime): Executed when the container boots up (e.g. CMD ["node", "app.js"]). Sets the default process to run inside the container.

COPY vs. ADD

• COPY (Recommended): Simple, transparent copying of local files/folders into container.
• ADD (Advanced): Copies files AND can automatically extract local .tar.gz archives or fetch remote HTTP URLs. Use COPY unless tar extraction is required!

⚡ Step 3 — Build Performance Optimization

Docker Build Layer Caching (5 Mins ➔ 2 Secs!)

Every instruction in a Dockerfile creates an immutable layer. If a layer changes, ALL subsequent layers must be rebuilt from scratch!

❌ Bad Dockerfile (Invalidates Cache Every Edit)

FROM node:18-alpine
WORKDIR /app
COPY . . # Copies entire source code first!
RUN npm install # Takes 3 minutes every edit! 😭
CMD ["node", "server.js"]

⚠️ Every time you edit a 1-line JS file, `COPY . .` changes, invalidating cache. Docker re-runs `npm install` from scratch every build!

✅ Optimized Dockerfile (Blazing Fast Caching)

FROM node:18-alpine
WORKDIR /app
COPY package*.json . # Copy manifest only!
RUN npm install # CACHED unless dependencies change! 🎉
COPY . . # Copy source code after!
CMD ["node", "server.js"]

🚀 Code edits only invalidate the final `COPY . .` step. `npm install` is fetched instantly from Docker cache in 1.5 seconds!

🏗️ Step 4 — Enterprise Production Best Practice

Multi-Stage Builds (Shrink Image from 800MB to 100MB)

In Java (Maven) or React apps, you need heavy build tools (JDK, Maven, Node) to compile your code. But in Production, you ONLY need the compiled JAR or static HTML! Multi-Stage Builds let you compile in Stage 1 and copy ONLY the compiled artifact into a tiny Stage 2 image!

# STAGE 1: Build Java Application with Heavy Maven (~800MB)
FROM maven:3.8.6-openjdk-17 AS builder
WORKDIR /build
COPY . .
RUN mvn clean package -DskipTests

# STAGE 2: Lightweight Production JRE Image (~120MB)
FROM openjdk:17-jdk-slim
WORKDIR /app
COPY --from=builder /build/target/app.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "app.jar"]
