4. OOP Using Food Ordering Application

Objective: Design backend entities of the Food Ordering Application using core OOP principles.
  • Identify Domain Entities: Customer, MenuItem, FoodItem, BeverageItem, Order, OrderItem, Address.
  • Abstraction: abstract class MenuItem defining abstract methods calculateTax() & getCategory().
  • Inheritance (IS-A): FoodItem extends MenuItem & BeverageItem extends MenuItem using super().
  • Encapsulation: Protecting Customer.walletBalance via private fields and controlled deductBalance() operations.
  • Polymorphism:
    • Method Overriding (Runtime Polymorphism): @Override calculateTax() in FoodItem (5% GST) vs BeverageItem (18% GST).
    • Method Overloading (Compile-Time Polymorphism): Overloaded placeOrder(items) vs placeOrder(items, couponCode) in OrderService.
  • Composition (HAS-A): Order HAS-A Customer and List<OrderItem>.
⚡ Live OOP Codebase (FoodOrderingSystem Repo):
MenuItem.java (Abstraction) FoodItem.java (Inheritance) BeverageItem.java (Method Overriding - Runtime Polymorphism) OrderService.java (Method Overloading - Compile-Time Polymorphism) Customer.java (Encapsulation) Order.java (Composition)
