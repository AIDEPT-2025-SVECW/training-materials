Topic 05

Epics & Capability Bundles

Structuring product features into high-level functional capability buckets.

What is an Epic in Agile?

An Epic is a major product feature or capability that is too large to complete in a single sprint. Epics serve as organizational containers for related User Stories.

TastyDash Core Epics Breakdown

👤 Epic 1: User Account & Profile Management

Core Infrastructure

Description: Everything related to onboarding food delivery customers, authentication, security, and address management.

📝 US-101: Customer Phone OTP Sign Up & Authentication
📝 US-102: Save Multiple Delivery Addresses (Home, Office, Friend's Place)
📝 US-103: Manage Dietary Preferences (Vegetarian, Vegan, Gluten-Free)

🍔 Epic 2: Restaurant Catalog & Menu Discovery

Discovery Feature

Description: Restaurant discovery, menu browsing, food search, cuisine filters, and dish customizations.

📝 US-201: Filter Restaurants by Cuisine (Italian, Mexican, Indian, Chinese)
📝 US-202: Real-time Search by Dish Name ("Pepperoni Pizza", "Sushi Roll")
📝 US-203: Customize Dish Options (Choice of Crust, Extra Cheese, Spice Level)

🛒 Epic 3: Cart, Checkout & Payment Gateway

Monetization Feature

Description: Shopping cart state management, delivery fees, taxes, discount promo codes, and payment execution.

📝 US-301: Add/Remove Items from Shopping Cart with subtotal updating
📝 US-302: Apply Promo Coupon Code at Checkout
📝 US-303: Pay securely via Credit Card / Debit Card / UPI

📍 Epic 4: Real-time Order Fulfillment & GPS Tracking

Logistics Feature

Description: Live order status updates (Kitchen Preparing, Driver Picked Up) and map GPS tracking.

📝 US-401: Track Delivery Driver live on interactive Google Map
📝 US-402: Call/SMS Delivery Partner directly from order screen
📝 US-403: Rate & Review Restaurant & Driver after order delivery
