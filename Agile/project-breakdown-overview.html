Topic 03

Agile Project Hierarchy Breakdown

How high-level business visions decompose into actionable daily developer tasks.

The 4-Tier Decomposition Pyramid

In Agile engineering, a large product vision like TastyDash is too big to assign directly to a developer. We decompose it into 4 clear levels:

🚀

Level 1: Release / Milestone

Strategic Container

Target version launch container delivering major functional value to market.

🍔 TastyDash Example: Release 1.0 (MVP Launch)
📦

Level 2: Epic

Feature Group

A large product capability spanning multiple sprints and containing multiple user stories.

🍔 TastyDash Example: Epic B — Restaurant Menu Search & Filter
📝

Level 3: User Story

User Requirement

Short requirement statement: "As a [role], I want [goal] so that [benefit]." Estimated in Story Points.

🍔 TastyDash Example: "US-101: As a customer, I want to filter restaurants by cuisine (Italian, Asian) so that I find relevant food fast." (3 pts)
🔨

Level 4: Task / Subtask

Technical Action Item

Granular technical work items assigned to developers and estimated in hours.

🍔 TastyDash Example: Task 1: Build GET `/api/v1/restaurants?cuisine=italian` API endpoint (Backend - 4 hrs)
