Topic 07

Technical Tasks, Subtasks & Estimation

Decomposing User Stories into engineering action items estimated in hours.

What is a Technical Task?

While a User Story describes WHAT the user wants, a Technical Task defines HOW the engineering team will build it. Tasks are granular implementation items estimated in Hours and assigned to specific developers.

Decomposing TastyDash User Stories into Tasks

📝 Story US-201: Filter Restaurants by Cuisine (Estimated: 3 Story Points)

To complete this 3-point User Story, the engineering team decomposes it into 4 technical subtasks:

Task ID & Title Technical Action Item Description Role Assigned Est. Hours
TASK-201.1
DB Indexing		 Create compound index on `{ cuisine: 1, is_active: 1 }` in MongoDB `restaurants` collection. DB Engineer 2 Hours
TASK-201.2
Backend API		 Build Express router endpoint `GET /api/v1/restaurants?cuisine=italian` with query validation. Backend Dev 4 Hours
TASK-201.3
Frontend UI		 Create `CuisineFilterPills` React component with active filter state and Redux store dispatch. Frontend Dev 3 Hours
TASK-201.4
Integration Test		 Write automated Cypress E2E test simulating customer tapping cuisine pill and verifying list UI. QA Engineer 3 Hours
📝 Story US-302: Apply Promo Coupon Code at Checkout (Estimated: 5 Story Points)

Engineering task decomposition for the promo coupon discount engine:

Task ID & Title Technical Action Item Description Role Assigned Est. Hours
TASK-302.1
Coupon Verification API		 Build `POST /api/v1/coupons/validate` logic checking expiration date, minimum cart subtotal, and user usage limits. Backend Dev 5 Hours
TASK-302.2
Checkout Input Form		 Build React coupon input field, apply button, and dynamic discount banner recalculating checkout total. Frontend Dev 4 Hours
TASK-302.3
Security Vulnerability Test		 Audit coupon API against price manipulation, replay attacks, and concurrent coupon double-redemption. Security QA 3 Hours

User Story vs. Technical Task Comparison

Dimension User Story Technical Task
Perspective End User / Customer ("As a customer...") Developer / Engineer ("Build GET API route...")
Primary Focus Business Value & Customer Outcome Technical Implementation & Code
Estimation Unit Story Points (Fibonacci: 1, 2, 3, 5, 8) Hours (e.g. 2 hrs, 4 hrs)
Primary Owner Product Owner / Business Analyst Software Engineers & QA Testers
