Topic 06

User Stories, Acceptance Criteria & Story Points

Mastering user-centric requirement engineering and Fibonacci story estimation.

Anatomy of a User Story

A User Story expresses a product feature from the perspective of the end user rather than technical jargon.

Standard User Story Template:

"As a [Type of User], I want [Goal / Action] so that [Business Benefit]."

Detailed TastyDash User Story Examples

📝 US-201: Cuisine Type Filter
Story Points: 3 (Medium)
User Story Statement:
"As a hungry customer, I want to filter restaurants by cuisine type (e.g. Italian, Indian, Mexican) so that I can quickly find food that matches my current craving."
✅ Acceptance Criteria (Behavior-Driven BDD Format):
• Scenario 1: Filter Selection — Given I am on the TastyDash home screen, When I tap the "Italian" cuisine pill, Then the restaurant list re-renders showing only restaurants tagged with Italian cuisine.
• Scenario 2: Empty Filter State — Given no restaurant matches a selected cuisine filter, Then display an empty state vector graphic: "No Italian restaurants near you yet."
📝 US-203: Food Item Customization
Story Points: 5 (High Complexity)
User Story Statement:
"As a customer, I want to select dish customizations (extra cheese, crust type, spice level) before adding to cart so that my meal is prepared to my exact taste."
✅ Acceptance Criteria (Behavior-Driven BDD Format):
• Scenario 1: Modal Options — Given I click "Custom Pepperoni Pizza", When the customization modal pops up, Then I can select 1 Crust radio button and multiple Extra Toppings checkboxes ($1.50 each).
• Scenario 2: Dynamic Price Recalculation — Given I check "Extra Mozzarella", When the checkbox state toggles, Then the modal subtotal price instantly updates from $12.00 to $13.50.
📝 US-302: Promo Coupon Code Application
Story Points: 5
User Story Statement:
"As a budget-conscious buyer, I want to apply a promo coupon code (e.g. TASTY20) at checkout so that I receive a discount on my total order price."
✅ Acceptance Criteria (Behavior-Driven BDD Format):
• Scenario 1: Valid Coupon — Given I type code "TASTY20" into the coupon input, When I click "Apply", Then 20% is deducted from my cart subtotal and a green banner displays "20% Discount Applied!".
• Scenario 2: Expired Coupon — Given I type expired code "SUMMER2024", When I click "Apply", Then a red error message displays "Coupon code has expired."
