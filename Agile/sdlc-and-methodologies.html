Topic 01

SDLC & Software Methodologies

Understanding how structured engineering processes turn software concepts into reliable applications.

What is a Software Development Methodology?

Building software is like constructing a multi-story building. Without a blueprints process, chaos ensues—engineers write conflicting code, costs balloon, and products fail to launch.

A Software Development Methodology provides the standard process, roles, tools, and rules that guide software development from initial concept to live maintenance.

🍔 TastyDash Case Study Context: Why We Need a Methodology

Imagine starting TastyDash without a process. The backend developer designs an order API assuming payment happens in cash, while the frontend developer builds a credit card form. The tester doesn't know how delivery fees are calculated. A software methodology aligns everyone on requirements, API contracts, and quality standards before launching to hungry users!

The 6 Phases of SDLC (Applied to TastyDash)

1

Requirements Analysis

Product Managers gather user needs, business goals, and technical feasibility.

TastyDash Example: Research shows users want to order food in under 3 clicks and track their driver on a map.
2

System Architecture & Design

Software Architects design database schemas, REST APIs, and UI mockups.

TastyDash Example: Designing MongoDB collections for `Users`, `Restaurants`, `MenuItems`, and `Orders`.
3

Implementation & Coding

Engineers write clean, modular source code following coding standards.

TastyDash Example: Writing Node.js Express controllers for `POST /api/orders` and React shopping cart components.
4

Testing & Quality Assurance

QA engineers verify functionality, security, performance, and bug fixes.

TastyDash Example: Verifying discount coupon calculations ($5 off orders over $25) and edge cases.
5

Deployment & Release

Deploying application builds to cloud environments (AWS, Docker, Vercel).

TastyDash Example: Deploying TastyDash v1.0 microservices to Docker containers behind Nginx load balancers.
6

Operations & Maintenance

Monitoring system health, fixing live production issues, and gathering feedback.

TastyDash Example: Monitoring database performance during Friday night dinner traffic spikes.
